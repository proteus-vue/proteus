## 决策 #1279 · 内置终端（pty）落地
用户方向选择：内置终端（pty）。
- Rust `src/term.rs`：`openpty + fork + execve`（**不引 libc/portable-pty**），子进程 `setsid + TIOCSCTTY`（Ctrl-C 只打给 shell），
  fork 前把所有 CString 造好（Tauri 多线程下 fork 死锁纪律）；读线程按 **UTF-8 边界**切（否则中文变 `�`）；
  spawn 抽成 `spawn_pty()` 以便单测 → `pty_runs_echo_and_reads_back`（真跑 /bin/echo 读回）等 3 条 Rust 测试绿。
- 前端：`ui/src/terminal.ts`（零依赖 ANSI：光标/滚动/擦除/SGR 16+256+真彩/备用屏，未知序列吞掉）
  + `panels/TerminalPanel.vue`（等宽标尺量 cols×rows → 喂 pty；键盘翻字节：Enter=`\r`、Ctrl-C=`\x03`、方向键=`ESC[A`、Backspace=`\x7f`；
  IME/粘贴走 input 事件）。v-show 常驻 + **第一次显示才开 shell**（不然白起登录 shell）。
- ★两个真坑：① `Terminal` 是普通对象，`cols/rowsCount` 这类 computed **没有任何响应式依赖会被永久缓存**
  ⇒ term_open 拿到 146×47、界面却画 80×24（折行全错）。规矩：读 `term.value.*` 的 computed 首行 `void ver.value`。
  ② `switchView` 原来只判 `code` 才把原生画布收 0×0，加 term 后必须泛化成 `v !== 'device'`（否则 GL 浮在终端上）。
- 判据 ㊼（`scripts/studio-panel-probes-term.mjs`）：命令名三方对齐（term.rs↔main.rs↔bridge.ts）+ 点 rail 开 146×47
  + ANSI 上色（ERROR=rgb(229,83,75)/OK=rgb(57,192,122)）+ 按键序列 + resize 到 67 列。
  破坏性验证：Enter 改 `\n` ⇒ ㊼ 准确翻红（已还原）。**67/67 全绿**。
- 又拆一次文件：`check-studio-panel.mjs` → 1013 行 ⇒ 把 ㊻㊼ 挪进 `scripts/studio-panel-checks-ui.mjs`（974 行）。
- 环境坑：`check-file-size` 前台跑被 120s 超时杀掉（冷缓存扫 2487 文件要 ~2min）⇒ 放后台跑即绿。

  （2500ms 命中一次、8000ms 没命中）⇒ 注释里已标 best-effort，真窗口那一步只能人眼验。
