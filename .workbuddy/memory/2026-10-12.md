## ★实证：`p-svg-canvas/path-parser.ts` 有**真挂死点**（非法 path 输入）

- **根因**：`tracePath`（L117-266）主循环里，`i` 只在两种情况推进——① 本轮 token 是**命令字母**（L131-133 `i++`）② 走 `num()` 的 `i++`。而 `case 'Z'/'z'`（L254-260）**既不消费 token 也不推进 i**。于是当 `cmd` 已是 `Z/z` 且下一个 token 是**数字**时（非法 path 数据），循环体状态零变化 ⇒ **原地无限循环**。
- **触发样例（实测，node --experimental-strip-types 跑真实源码）**：`"M0 0Z 5"`、`"M0 0h10v10z5"`、`"m0,0 l10,0 z0"` → 20k 轮 closePath 未退出（SPIN）。
- **两种崩溃形态（同一根因，取决于调用链）**：
  - `tracePath` 直绘（`engine.ts:361`）→ **JS 线程永久卡死**（页面无响应、不可恢复）。
  - `getPointAtLength`（`engine.ts:191`，animateMotion 每帧采样）→ `collectPoints.closePath` 每轮 `pts.push()` ⇒ 内存无限增长 ⇒ **实测 4 GB heap OOM，进程 FATAL ERROR**（约 40 秒）。
- **输入可控性**：`d` 来自 SVG 源（`engine.ts:358` `node.d` = `<path d>`；`engine.ts:182` `a.values[0]` = `animateMotion path`）⇒ 设计工具导出 / LLM 生成 / 手写 SVG 都可能出现 `z`+数字。
- **现状**：仓库现有资产**未命中**该模式（`d="…[Zz][ ,]?[-0-9]` 全仓 grep 仅命中无关的 `z-index`）⇒ **潜伏未触发**。
- **验证过的补丁（/tmp 副本上跑通，合法路径行为不变）**：`tracePath` 主循环记 `const iBefore = i`（L130 后），循环尾 `prevCmd = cmd` 之后加一行 `if (i === iBefore) i++` —— 保证每轮必推进，且对未来新增"不消费 token"的分支结构性免疫。补丁后三例全部 `terminated`（closePath 幂等，非法输入会多一次 close，无副作用）。
- **附带健壮性问题（不挂死）**：① 截断路径 `"M0 0 L"` ⇒ `Number(undefined)=NaN` 传播，`getPathLength` 返回 NaN、`getPointAtLength` 返回 `(NaN,NaN)`；② `arcTo` 起终点重合（x1p=y1p=0）⇒ 分母 0 ⇒ coef=NaN。
- **未落地**：补丁只在 `/tmp/pp-probe` 副本验证，**仓库源码未改**（待用户拍板，需配决策条目 + `tests/svg-canvas.test.ts` 回归用例）。
