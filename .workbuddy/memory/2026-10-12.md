- **产出**：`docs/mp-dynamic-component-plan.md`（调研稿 + 落地方案，待拍板；**未立项、未登记 board-inventory**）。
- **现状取证（三端）**：
  - Web = Vue 运行时原生支持（不走 Proteus 编译链）。
  - App/Vapor = 已落地 P3「首帧组件名解析」（`compiler/src/vapor/template.ts:4286` + `vapor/build.ts:437` → `SubscriptionTable.componentIs`；实例化 `slot-runtime/src/instantiate.ts:798`），判据 ⑲；边界=运行时切换不支持。

- **平台取证**：WXML 无 `<component :is>`；可用机制三选——`wx:if` 分支（惰性/销毁重建）、`<template is="{{...}}">`（官方明说 is 支持 Mustache 动态，但模板作用域隔离）、抽象节点 `generic`（**调用方静态指定**、不支持运行时切换 → 排除）。佐证：本仓 `docs/compiler-platform-alignment.md` §1.1 官方 ElementKind 已含 `If`（分支组）与 `TemplateRef` 一等等级语义。
- **推荐主方案**：编译期候选集穷举 → **`wx:if` 分支组**（真组件、props/事件走既有序列化链、**天然支持运行时切换**）；备选 `<template is>` 动态（作用域隔离代价，列为后续瘦身）；附带收益=`<KeepAlive>` 可用 `hidden` 常驻映射落地。
- **关键约束**：候选集必须**源码静态可扫描**（因 `gen-routes.collectComponents` + `tag-scan.collectUsedFrameworkComponents` 都基于源码扫描）⇒ 需显式声明（推荐 `:is-candidates` 属性 + 静态推断兜底，取不到即编译期 error）。
- **改动切面四处同源**：compiler 模板降级 / vue-compat 矩阵状态 / plugin-vite（usingComponents + 按需输出）/ 规则注册表与双语文案。连带的 `tag-scan.ts:161` 诚实边界（"仅识别静态标签"）也须同步更新。
