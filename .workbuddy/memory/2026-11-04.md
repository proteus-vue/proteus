  （Volar 的 TS 特性靠 tsserver 插件，单独跑 server 拿不到）。
- 正确路线：**直接驱动 tsserver**（typescript 自带，零新增依赖）

  ⇒ 任何"按项目"的检查都会返回空。新增 `packages/studio/ui/tsconfig.json`（给常驻服务），

- .vue 边界：tsserver 不认 SFC ⇒ 实时需 `@vue/typescript-plugin` + tsconfig plugins；当前由保存后 <1s 的 watch 覆盖。

## 决策 #1423 · 悬停提示"闪跳" = 诊断重复派发
- 根因：`setDiagnostics` 是真实事务，会重建 lint 状态与 hover tooltip；而诊断数据频繁"内容不变、对象换新"
  （tsserver/eslint 每次推送新数组）⇒ 悬停期间被反复重画。
- 修：`applyDiagnostics` 加**签名去重**（path + 每条 from/to/severity/source/message）；内容不变不 dispatch。
- 新增 `repaintDiag()` = 清签名 + 派发，用于换 state 必须重画的场合。
- ★补漏：`open()` 的**缓存分支**（切回已打开文件，不读盘）之前没有派发 ⇒ a→b→a 后波浪线消失。
- 验证：tooltip 保持、removedNodes=0；a→b→a 后波浪线仍 1；面包屑 5 段且文本仍等于完整路径。
- 瘦身：面包屑逻辑 → `ui/breadcrumbs.ts`；CodePanel 993 行（1000 上限内但要留余量）。

## 决策 #1424 · 悬停提示"闪跳"根因（录屏取证）
- 录屏抽帧（ffmpeg fps=1.5/8）看到：同一诊断上横移鼠标，提示框从"窄3行"跳到"宽2行"、横移 200+px。
- ★三层原因：
  1. 我们**没装 `linter()`** ⇒ 正文波浪线根本没有 hover 提示（实测返回 null）；能弹的只有行号标记的；
  2. 行号标记提示位置 = "标记 + 鼠标位置" ⇒ 横移就重定位（跳）；
  3. 它和我们的提示被塞进**同一 tooltip 容器** ⇒ "两层框"。
- 修：`diagLint.diagHover()` 自实现 `hoverTooltip`，**`pos` = 诊断起点**（横移不重定位）；
  `lintGutter({ tooltipFilter: () => [] })` 关掉自带提示；CSS 隐掉残留 `.cm-tooltip-section.cm-tooltip-lint`；
  容器透明、配色固定深色 + `!important`（CM 主题会覆盖 section 背景）。
- 验证：横移两处 hover 框 x/y/w/h 完全一致（位移 0px）；可见 section = 1；配色 rgb(31,34,40)。
- ★`lintGutter` 的 `tooltipFilter` 只挡 gutter 提示，挡不住 lint 塞进容器的段 ⇒ 仍需 CSS 兜底。
