## 决策 #1417 · 诊断与文档版本对齐（用户实测"改回正确代码反而爆红"）
- 真因：诊断是**起进程跑 tsc**，结果回来时文档已改过多次，旧结果按**行号**映射到新文档 ⇒ 错误画到错位置。
  **不是延迟问题，是版本没对齐**。
- 修：`editedAt`（每次 docChanged 打点）+ `diagStale = editedAt > diagAt`；`linter` 在 stale 时返回空
  （宁可不报也不报错位置）。
- `scheduleAfterEdit()`：停手 700ms 触发，最小间隔 8s（防打字时反复起进程）。
- **quick 模式**：编辑触发只跑 tsc；eslint(15s) 只在进视图/保存/手动跑，复用上次结果。
- ★诚实边界：仍是"准实时"（0.7s 触发 + tsc 3–12s）。真·实时需**长驻语言服务**（tsserver/vue-tsc watch + LSP），
  属独立工程。
- ★顺手恢复：`useDeviceKeyboard.ts:26` 留着测试用的 `constt FLUSH_MS = 30`（语法错误、阻塞构建），按 HEAD 改回 `const`。

## 决策 #1418 · 类型诊断改常驻 watch（用户第二次不满后重做）
- ★★根因两个叠加：
  ① **每次 spawn vue-tsc 要 3–12s**（冷启动全量）；`--watch` 模式**增量 <1s**
     （实测 16:31:27 写文件 → 16:31:28 出结果）。
  ② **`forceLinting` 对外部数据无效**：`force() { if (this.set) ... }`，`set` 首次 lint 后置 false，
     只有 `docChanged` 复位 ⇒ 推送后调它**静默无操作**（lint source 调用数不增加，波浪线永不刷新）。
     外部数据必须用 **`view.dispatch(setDiagnostics(state, list))`**。
- 后端：`diag_watch_start` 常驻 `vue-tsc --watch --preserveWatchOutput`，按批次 emit `diag:update`；
  watch 输出格式与一次性不同（`路径:行:列 - error TSxxxx:` vs `路径(行,列): error`），不能共用解析器。
- `diag_watch_stop` + `RunEvent::Exit`：退出必须 kill，否则孤儿 tsc 长期吃 CPU。
- 前端：stale 判据改为 **`editedAt > savedAt`（内存 ≠ 磁盘）**；四个时机主动 `syncLint()`。
- ★剩余边界：watch 读**磁盘** ⇒ 未保存输入不检测（保存即 <1s）。真·实时需内存语言服务（tsserver + @vue/language-core）。
- 状态：门禁 68/68、类型 0 错误、eslint 15；CodePanel 996 行（接近上限，下次改动需先拆）。

## 决策 #1419 · 内存语言服务（Volar LSP）—— 不保存也能诊断
- 三层诊断：**内存 LSP**（编辑器波浪线，编停 220ms 推送）· **磁盘 watch**（面板全貌，保存后 <1s）·
  **eslint**（一次性 15s）。同文件并存时**内存 LSP 优先**。
- `packages/studio/diag-lsp.mjs`：极简 LSP 客户端（Content-Length 分帧），起 `vue-language-server --stdio`；
  ★`initializationOptions.typescript.tsdk` 必须显式指向仓库 typescript；
  ★服务端请求（registerCapability 等）必须回 `null`，否则它一直等、后续诊断不推。
- Rust：`diag_lsp_start/sync/stop` + 事件 `diag:update-file`；退出钩子与 watch 一并 kill。
- 前端 `diagSync.ts`：`syncOpen/scheduleSync(220ms)/syncClose` + `liveDiag`；`diagsOf` 优先内存级。
- ★纠错1：**不能等 ready 才推**（ready 丢失 ⇒ 永不同步）；总是推 didChange，ready 只用 pending 补发。
- ★纠错2：`syncClose` 要放在"确认关闭"之后（否则取消关闭会让文件失去实时诊断）。
- 依赖待装：`pnpm add -w @vue/language-server@2.2.12`（未装时脚本 exit(3) 并上报，watch 不受影响）。
