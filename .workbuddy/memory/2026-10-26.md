## 联动（决策 #1253）
- 点改动清单项 = 打开该文件 + 直接进 Diff 且来源 HEAD（VS Code SCM 语义）；清单里当前文件亮左侧强调条。
- 走 `open(path, { diff })` 而不是另写 `openAndDiff()`：打开与看差异必须同一条状态路径。
- 修真缺陷：`headText` 是上一个文件的 HEAD，原读盘分支只 `refreshDiff()` ⇒ 切文件后变成「A 的 HEAD vs B 的缓冲」
  （行号连续、增减合理、内容全错且不报错）；`syncDiffAfterOpen()` 按文件重取。
- 踩坑（自己写的）：`GitBar` emit 的是**路径字符串**，`openChanged` 却按 `GitFileStatus` 取 `f.path` ⇒ undefined ⇒
  `open()` 直接返回、点了没反应。判据 ㉞ 当场抓住；用临时脚本（页面内 DBG 日志）定位。
