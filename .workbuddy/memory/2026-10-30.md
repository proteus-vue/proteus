## 决策 #1398 · IDE 整体缩放（⌘= / ⌘- / ⌘0）
- 此前只有**设备画面**缩放（stageGeom.setZoom），整个界面没有缩放手段。
- Rust 命令 `set_ui_zoom` → `Webview::set_zoom`（v2 原生 pageZoom，连布局一起缩放 ⇒ 画布矩形不错位）。
- `layout.ts: uiZoom`（0.7–1.6，步进 0.1），随 `studio.layout.v1` 持久化；启动即应用。
- App：⌘= / ⌘- / ⌘0；缩放后必须 `syncRect()` + `saveLayout()`。
- 与终端字号**分流**：target 在 `.termwrap` 内不接管（终端自己处理）。
- 验证：启动应用 1；非终端 1→1.1→1.2→⌘0 1；终端内 ⌘= 不调 set_ui_zoom、终端字号 12→13。
