## 2026-10-16 10:31 「为什么 iOS 浅底发白还能保证内容可读」——机理 + 我们的根因

存证：`.workbuddy/salvage/liquid-glass/white-bg-1621/{ghost_cmp,chk_ios_bar,chk_ours_bar,read_*}.png`，
脚本 r1/r6/r7/r8/r9/r10.py。

### ★ 核心机理：iOS 把「发白」和「可读」解耦——发白靠霜色 V，可读靠恒定 α
- iOS 浅底面纱 = **线性透射** `glass = 0.533·bg + 0.467·V`，**α=0.467 恒定**，V=236(亮霜)/140(暗霜)。
- 「发白」来自**霜色 V 是近白**（236），「可读」来自 **α 恒定 0.467 保住内容对比**——两个量各司其职。
- 线性透射不破坏内容的相对明暗：黑字 bg=0→110，白底 bg=255→246，**ΔL 从 255 保留到 136（53%）**，
  在亮背景上绝对差 136 完全可读。
- 像素实证（ghost_ios.png，拉伸[186,245]）：条内文字鬼影（"叶睡叶睡"/"注册"/"内购"）**成形可读**。

### ★ 我们的根因：浅底 α=0.85 + V=1.0 把内容洗白
当前 `glass.wgsl:329` `VEIL_A0 = mix(0.467, 0.85, veil_t)`，`:305` `VEIL_V = mix(0.55, 1.0, veil_t)`。
浅底（veil_t=1）：α=**0.85**，V=**1.0**(255) ⇒ glass = 0.15·bg + 0.85·255：
- 黑字 bg=0 → **217**（iOS 是 110）；白底 bg=255 → 255；**ΔL 只剩 38**（iOS 136）⇒ **3.6 倍差距**。
- 像素实证（ghost_ours.png，拉伸[196,255]）：条内鬼影（"使命"）淡到勉强可辨 ⇒ 内容洗白。
- 即：**模糊链 #1005 已对齐 iOS（MTF≈0.5），但面纱 α=0.85 在模糊之后又压掉 5.7×（0.15/0.533）**。

### ★ 决策摇摆史（α 恒定 ↔ 分档 反复横跳，每次只修好一半）
- #984：恒定 α=0.467（四点拟合）
- #987：浅底 α→0.88（用户「浅底内容应像 iOS 那样看不见」）
- #992：撤回回 0.467（用户「折射要内容可见」）
- #996：又回 0.85（用户「iOS 灰底滑到玻璃下只剩文字，我们灰底还清楚」）
- **根源**：想用**单一全局 α** 同时满足「灰底融霜」与「黑字可读」——数学上不可能（线性同比压缩两者）。

### ★ 正确解法：恒定 α + 对比度门控（内容自身对比度决定可见性）
- iOS 不需要调 α：**恒定 α 下，高对比内容（黑字 Δ255→Δ136）透射后仍可读，
  低对比内容（灰底 Δ15→Δ8）透射后绝对差小、自动融霜**——门控是免费的。
- 我们 α=0.85 是为了「灰底融霜」强行加大 α，代价是黑字也被洗白（= 用户本条抱怨）。
- 修复：浅底 α 从 0.85 降回 **0.467 恒定**；「发白」靠 **V=0.925(236)**（不是 1.0）+ α 恒定。
  条面 = 0.533×255+0.467×236 = **246**（够白，iOS 253 差 7 可接受）；黑字透射 110（可读）。
- 与 #988 张力：#988 把 V 拉到 1.0 是因「我们 236 偏灰」——但那是想对齐条面 253，
  代价是暗端被抬到 217。**取舍：要条面纯白 253，还是内容可读。iOS 选了内容（条面 246）。**

  「边缘镜像反射」应**反射条外内容**到边缘（水面倒影语义），不折叠条内内容。
- 折叠判据：`|d(bend)/dd| < 1` 处处成立（当前 (1-e)³ 在 e→0 处斜率 3·bend(0)/band ≈ 3.6 > 1 ⇒ 折叠）。

## ★★★ 2026-10-16 15:40 更正：上节「折射折叠毁结构」的诊断**错误**（被 #1010 证伪）

上节判「(1-e)³ 非单调 ⇒ 采样点越界折叠」——**错在漏符号**。数学复核：
- s(d) = d − bend(d)，bend=(1-e)³·band·ER·str ⇒ bend'(d) = −3(1-e)²·ER·str **<0**；
- **s'(d) = 1 − bend'(d) = 1 + 3(1-e)²·ER·str > 0 恒成立**（数值：s'(0)=3.63 → 全程正值）⇒ 映射**处处单调、无折叠**。
- 判据写错在哪：把 "1+bend' 的绝对值 3.63 > 1" 读成了"折叠"。**折叠的正确判据 = s' < 0**（从不为真）。

"越界采样"的真相 = **信号不是 bug**：d<22.5px 带内 s(d)<0 ⇒ 采到**条外上方**内容（−66..0px 被压缩 3.6× 引入顶部带）
——这正是 #998 用户要的「边缘镜像反射」、#1006 验收「折射终于对了」的同一机制。
本会话按此诊断实施的 #1009（bump + ER 0.15）已由 **#1010 撤回**（恢复 (1−e)³ + 1.20）——用户实测「折射和边缘反射都消失了」。
