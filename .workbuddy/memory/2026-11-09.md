## ★★★教训：不 fetch 就断言"远端没有"（本会话连错两次）
- 第一次：只看当前 HEAD ⇒ 说"11-06 起无提交"。
- 第二次：用 `git log --all --grep=格式化` 说"全历史零命中"——**`--all` 读的是本地缓存的
  remote ref，不 `git fetch` 就看不到新提交**。用户说"昨天推送了"是对的。
- **正确做法**：下"没有实现"这类否定结论前，先 `git fetch` 或 `git pull --ff-only`，
  再看 `origin/main`；否则否定结论只是在证明"我的本地视图里没有"。
- 连带纠正：`behind 59` 是拉取前的旧数，实际落后到 **11-08 13:23（17 个提交）**。
