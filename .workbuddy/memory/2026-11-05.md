## 决策 #1437 · 按住 ⌘ 时 quickinfo 顶替预览卡（三层原因）
- 现象：按住 ⌘ 弹出的是 `(alias) function setDiagnostics...` 类型提示，定义预览卡看不到。
- ★三层原因（缺一层都还会犯）：
  1. **typeHover 不认修饰键**：hoverTooltip 300ms 到点就弹，不管 ⌘ 是否按住；
  2. **异步竞态**：quickinfo 请求在途时按下 ⌘，`closeHoverTooltips` 关不掉未落地的结果；
  3. **层级**：DefPeek z-index **60** < CodeMirror `.cm-tooltip` **200**（baseTheme）⇒ 必被压下面。
- 修：新增叶子模块 `ui/modKey.ts`（修饰键唯一状态源，避免 nav↔modPeek 循环 import）；
  typeHover 开头 + await 后各判一次 `modHeldState`；diagHover 同样让路；
  keydown 里 `dispatch({effects: closeHoverTooltips})` 收掉已显示的；DefPeek z-index → **250**。
- 验证：单纯 hover tip=1；先 hover 再按 ⌘ → tip=0/peek=1；按住移动仍 0/1；松开 peek=0 且再 hover tip=1。
- eslint 0 / 类型 0 / 门禁 68 / CodePanel 998。已推送 bc456ca7。
- 通用教训：**同一坐标上的两类浮层必须互斥**（显式判定 + 主动关闭 + 层级兜底），
  只做其中一件都会复现「谁后到谁盖住」。
