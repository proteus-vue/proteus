## 决策 #1428 · tsserver 自动补全 + 括号自动闭合
- `closeBrackets` 来自 `@codemirror/autocomplete`（已装 6.20.4）；`closeBracketsKeymap` 必须在
  `defaultKeymap` **之前**（否则 Backspace 只删一半，留孤儿括号）。
- 补全链路：`autocompletion` → `tsCompletionSource`（async）→ Rust `diag_complete`
  （**id + 一次性 channel + recv_timeout 2.5s**，超时回空不报错）→ `diag-lsp.mjs` → tsserver `completionInfo`。
- ★**服务端必须自己取 prefix**：不传时 tsserver 回 **1084 条**全部成员跨 IPC；传了只剩 **3 条**。
- ★★**"源永不执行"的坑**：`async function source(){ return async (ctx)=>{} }` 返回 Promise，
  而 `autocompletion({override})` 只接受**函数**、不会 await 数组元素 ⇒ 补全静默失效（不报错、
  一次 diag_complete 都不发）。去掉外层 async 即恢复。
- 验证：脚本级 `cons` → 3 条；UI 桩：请求 1、候选 2、Enter 插入成功。eslint 0 / 类型 0 / 门禁 68。
- 已推送 bd30424d。
