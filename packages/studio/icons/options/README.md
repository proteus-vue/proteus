# Studio 图标候选 · 字母变形方向（决策 #1225）

当前已定稿的应用图标是 `../icon.svg`（**立方体 + 四角选中框**），本目录是**另一条方向**的探索：
**抽象字母变形的极简风格**——参考 Xcode / Android Studio 那一路：**一个强字形 + 品牌色容器**，
元素从官网立方体里**抽取**（等距角度、三面三色），而不是把整个立方体搬进图标。

| 文件 | 方向 | 一句话 |
|---|---|---|
| `p-monogram-facets.svg` | **A · 三块平涂** | 竖笔绿 / 碗上半紫 + 下半蓝 = 立方体三个面直接映射到字母 |
| `p-monogram-solid.svg` | **B · 白字 · 紫蓝底** | 单色字形，品牌只由底色承担（最接近 Xcode） |
| `p-monogram-brand.svg` | **C · 白字 · 三色底** | 底色紫→蓝→绿，绿只在角上作点缀（品牌三色都在，但不"彩虹"） |

| **`p-monogram-final.svg`** | **C 的精修版（成品）** | 径向补光 + 方角竖笔 + 碗与竖笔齐平 + 视觉居中 + 柔和投影 |

## 共用的几何（三份完全一致，只换容器与配色）

字母 **P**（Proteus），1024 画布，整体平移 `(-30, 2)` 做视觉居中：

```
竖笔    rect x=356 y=232 w=104 h=552  rx=52
碗      半径 114，圆心 (566,398)：408,284 → 566,284 →(弧)→ 680,398 →(弧)→ 566,512 → 408,512
线宽    104（与竖笔同宽，笔画粗细统一）
外接    376 × 552（占容器 67%）
容器    squircle 824 · r186 · 四周 100（macOS Big Sur 网格）
```

★两条制图约束：
1. **碗的线帽用 `butt` 而不是 `round`**：round 会在竖笔里鼓出两个半圆，接缝看起来像"耳朵"；
2. **竖笔最后画**，盖住碗的两个端头——接缝干净，且不用做布尔运算。

## 怎么渲染预览

```bash
node packages/studio/icons/make-icon.mjs   # ← 只认 icon.svg / icon-small.svg
# 候选单独渲染：
node scripts/.tmp-render.mjs  <svg> <out.png> <size>
```

（`.tmp-render.mjs` 是临时脚本，不入库；需要时按 `make-icon.mjs` 里的 `shot()` 写法现写一个。）

## C 的精修做了什么（决策 #1226）

| 项 | 打磨前 | 打磨后 | 为什么 |
|---|---|---|---|
| 容器 | 单向线性渐变（紫→蓝→绿一条带） | 主渐变 + **左上径向淡紫** + **右下径向绿**（绿是一束补光，不是色带） | 一条三色带在 32px 会糊成"彩虹"；改成两束光后，绿色只在角上出现，反而更像被照亮的实体 |
| 内边 | 一层白描边 | 上亮下暗的 **rim 渐变**（0.34→0.03） | 浅色壁纸/深色 Dock 上都能看见边界（Apple 的通用做法） |
| 竖笔 | 胶囊（上下全圆） | **方角**（平顶平底） | 胶囊底看起来像 UI 里的"药丸按钮"；方角才是字母的竖笔 |
| 碗 | 半径 114，顶端与竖笔有 8px 台阶 | 半径 114，**顶端与竖笔齐平**（台阶去掉） | 台阶是我把"外扩"用错了地方：P 的碗与竖笔顶端本该齐平 |
| 居中 | 未做 | **-32px 视觉居中**（外接框 386×556） | 机械居中会让字偏右：碗的质量在右，必须按视觉重心挪 |
| 深度 | 无 | **柔和投影**（dy 6 / blur 10 / 0.22） | 白字直接压在渐变上会"贴"不住；一点投影就浮起来了 |
| 小尺寸 | 同一张缩到底 | **另出 16/32**（放大 12%、去投影） | 32px 下投影会糊成一团灰；字形放大才认得出 |
