# 第一批

## 卡 VC0 · Skyline 几何 API 实测

**优先级**：⭐ 最高（一票否决）
**预估**：0.5–1 人日
**依赖**：无
**阻塞**：VC4-c

### 现状
微信开放社区反馈 Skyline 下 `boundingClientRect()` 返回 `left/top/right/bottom/width/height` **全为 0**，开发者工具与真机均复现。
但社区其他用法显示 Skyline 下在 `ready` 生命周期可取到值（如 `res[0].height`）。**结论冲突，必须实测。**

### 目标
确定 Skyline 端几何数据的可靠获取方式。

### 测试矩阵

| 维度 | 取值 |
|---|---|
| 渲染模式 | Skyline / WebView |
| 组件类型 | `view` / `text` / `image` / `scroll-view` |
| 生命周期 | `attached` / `ready` / `onReady` / 延迟 500ms |
| 基础库版本 | 至少 3 个版本跨度 |
| 平台 | Android / iOS / 鸿蒙 OS 版 |
| 工具 | 开发者工具 / 真机 |

### 验收

> **状态（2026-10-02）**：工具侧实测完成 → **结论 A. 完全可用**。
> 报告：`docs/Proteus_Skyline几何API结论报告.md` · 装置 `spike/vc0-skyline-geom/` ·
> 原始证据 `spike/vc0-skyline-geom/results/*.txt`（3 基础库版本 × 双渲染模式 × 全时机矩阵）。

- [x] 输出《Skyline 几何 API 结论报告》，明确属于哪种情况：
  - [x] **A. 完全可用** → 可用条件：id/class 选择器；组件内用实例句柄
    （`scope.createSelectorQuery()` 或 `.in(inst)`）；时机不敏感（attached 起即有值）；
    lib 3.0.0/3.4.6/3.6.6 一致；**属性/tag 选择器恒 null**（禁用）
  - [ ] B. 版本问题 —— 不适用（三版本一致）
  - [ ] C. 组件限制 —— 不适用（view/text/image/scroll-view 四类全可取）
  - [ ] D. 完全不可用 —— 不适用
- [x] 同时验证 Skyline 是否**允许注入自定义 JS 探针**（沙箱限制未知）
  → ✅ 允许：页面/组件 JS 可写 `globalThis`，`automation_evaluate` 同上下文回读成功
- [ ] 鸿蒙 OS 版小程序行为单独记录（官方称支持，需实测）——**待有鸿蒙设备/真机调试环境**
- [x] 若结论为 C 或 D，**VC4-c 必须采用产出式探针，不得依赖查询 API** —— 不适用（结论 A）；
  VC4-c 设计建议：查询式（对账）+ 产出式（持续采集）**两法并用**，见报告 §5

### 风险提示
若 Skyline 既不允许查询、也不允许注入探针，则 Skyline 端无法参与 L2 校验，
**必须回退为"L1 编译期 + L4 像素"组合，并在对外材料中明确说明覆盖范围。**
→ 本测**否定了该风险**（两条路都通）；残余风险仅真机差异（产出式探针兜底已内置）。

## 卡 VC5-a · 分级容差配置规格 ⭐

**优先级**：⭐ P0（关键）
**预估**：1.5 人日
**依赖**：VC3-a / VC3-b

### 🔴 核心约束：禁止全局差异阈值

**全局阈值是最危险的做法。**

> 一个 50×20 按钮的变色只占全高清页面的 **0.001%**，
> 在 0.01% 全局阈值下**必然漏报**——这正是传统方案漏报的根源。

### 分级容差表（基线）

| 属性类 | 容差 | 理由 |
|---|---|---|
| 结构类（位置 / 尺寸） | 严格（≤1px 或 ≤0.5% 取大） | 确定性高 |
| **颜色类** | **极严格（±1/255）** | **真 bug 高发区，确定性极高** |
| 字体属性（字族/字号/字重） | 严格相等 | 确定性 |
| **文本度量结果（宽度）** | **唯一允许宽带** | 三端引擎天然不同 |
| 圆角 / 阴影 / 渐变 | **不比数值，走 L4** | 非确定性 |

### 验收

- [ ] 容差配置按属性类分级，提供配置文件
- [ ] **代码中不存在任何"全页差异率 ≤ X% 即通过"的判定**
- [ ] 每个校验项单独判定，**单项失败即整体失败**
- [ ] 支持组件级 override，但**不得全局放宽**（有防护）
- [ ] 每新增校验项必须同时给出该属性类的**容差依据**，不得凭直觉设值
- [ ] 有反例测试：构造"按钮变色"case，验证在推荐容差下**必须被检出**
