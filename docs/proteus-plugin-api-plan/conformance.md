## 4. 负向用例（NEG-01 ~ NEG-08）

| ID | 场景 | 期望 |
|----|------|------|
| **NEG-01** | 调用未授予的 capability | `denied`，**插件不被终止** |
| **NEG-02** | WASM 执行 trap | `error:wasm-trap` + `isolated`，宿主存活 |
| **NEG-03** | 单次调用超 CPU / 内存限额 | `error:*limit-exceeded`，插件终止 |
| **NEG-04** | `network` 缺 hosts 白名单或含非法通配 | **安装期拒绝**（非运行时） |
| **NEG-05** | 老版本（`minVersion: 0.1.0`）插件 | 在 0.4.0 宿主上**仍可安装激活** |
| **NEG-06** | 含提案 API 的插件执行发布 | `proposal-not-publishable` 拒绝 |
| **NEG-07** | Tier 0 插件被激活 | **wasmInstances 不增加** |
| **NEG-08** | 清单声明未知提案名 | 清单校验拒绝 |

### ★ 一条由实测新增的语义断言

调试过程中发现：**未激活插件返回 `skipped`，已激活但越权返回 `denied`**——
二者语义不同，初版测试混淆了它们。

已固化为断言：

```
未激活 + 越权请求  → skipped (reason: not-active)
已激活 + 越权请求  → denied  (capability: xxx)
```

> **这正是 G-37「未实测不宣称」的价值**：
> 若不跑，会误以为"越权被拒"已被覆盖，实际测的是另一条路径。

## 5. 接缝命题

### 5.1 与 G-51 降级语义接缝

```
G-51 INV-02（能力缺失 → 降级 ≠ 崩溃）
   ∧ G-58 INV-EX-02（越权 → denied 不终止）
   ⇒ 权限系统不引入新的崩溃面
```

### 5.2 与 G-56.2 特权无关性接缝

```
G-56.2（自有宿主不享有内核特权）
   ∧ G-58 INV-EX-01（内置功能不享有 API 特权）
   ⇒ 特权无关性从「宿主」推广到「插件」
```

**这是第 21 次泛化的核心**：不绑定扩展来源。

### 5.3 与 G-54 能力探测教训接缝

```
G-54（禁用"发请求试探"探测能力）
   ∧ G-58 INV-EX-07（supports 为纯元数据查询）
   ⇒ 能力探测零副作用，畸形输入不抛异常
```

### 5.4 与 G-58 可观测性接缝

```
G-58 三层数据（L0/L1/L2）
   ∧ G-58 INV-EX-02（kernel.* capability）
   ⇒ 插件可申请消费框架语义，但仅限只读查询
```
