# 容器 Conformance 测试套件（C-01~C-08，38 项）

> **定位**: G-42 准入门禁
> **运行**: `node container-reference.cjs`（内置套件，38 项）
> **CI 集成**: `proteus conformance --container ./my-container.js`

---

## 套件总览

| 组 | 名称 | 项数 | 覆盖 |
|----|------|------|------|
| C-01 | 容器身份与能力 | 4 | id / version / capabilities |
| C-02 | 页面生命周期 | 5 | 创建/挂载/隐藏/显示 |
| **C-03** | **五原子销毁** | **6** | **G-42.2 核心** |
| C-04 | 页面栈治理 | 4 | 深度限制 / LRU / pop |
| **C-05** | **泄漏检测** | **5** | **G-42.1/39.3 核心** |
| C-06 | 配额管理 | 4 | 申请/超限/归还 |
| **C-07** | **沙箱与崩溃隔离** | **6** | **G-42.5 核心** |
| C-08 | 安全网关 + 仓库治理 | 4 | 签名/能力白名单/严禁 fork |

**合计：38 项**（实测 PASS=38 FAIL=0 SKIP=0）

## C-03 五原子销毁（6 项）★ 核心

| 编号 | 断言 | 对应步骤 |
|------|------|---------|
| C-03-01 | 销毁恰好 5 步 | G-42.2 |
| C-03-02 | 步骤顺序为 `unmount → unbindEvents → releaseResources → destroyIR → releaseQuota` | G-42.2 |
| C-03-03 | 挂载点已置空（Backend 已卸载） | ① |
| C-03-04 | 资源池总量归零 | ③ |
| C-03-05 | IR 实例已从注册表删除 | ④ |
| C-03-06 | 配额句柄已归还 | ⑤ |

**任一失败即不兼容**——这是根治页面栈泄漏的验收核心。

## 跳过规则

容器 Conformance **不允许跳过任何项**——所有 38 项均为准入必需。

（对比：G-27/G-40 允许按 `capabilities` 跳过不适用的项；但容器层的能力是"治理能力"，缺失即不合规。）
