# G-42 铁律与补充规则

> **原则溯源**: 原则 #0（统一语义收敛）· 原则 #11（可插拔必须有可验证支撑）
> **编号避让**: 本包使用 G-42.x 与 CMP059-066，与 G-41（CMP051-058）、G-40（CMP044-050）零冲突

---

## 一、铁律（G-42.1 ~ G-42.6）

### **G-42.1** IR 是页面唯一真相

> 页面状态必须由 IR 实例唯一持有。Backend 挂载点**不得独立持有业务状态**。

**理由**：传统框架泄漏的根因就是"JS 状态 ↔ 原生 View"两个 Owner 靠人工同步。单一 Owner 是从源头消灭泄漏的前提。

**违规示例**：
```js
// ❌ Backend 挂载点自己存了业务状态
mountPoint.userData = { cartItems: [...] }
```

**检查**：conformance C-03-05（IR 销毁后无残留）

---

### **G-42.2** 页面销毁必须五原子

> `unmount → unbindEvents → releaseResources → destroyIR → releaseQuota` 五步，**不可部分执行**。

**理由**：部分执行 = 泄漏。

**检查**：conformance C-03-01 / C-03-02（步数与顺序）

---

### **G-42.3** 资源由框架代管

> 业务代码**不得裸用** `setTimeout` / `setInterval` / `addEventListener`。
> 必须走 `pageContext.timer()` / `pageContext.on()` 等框架代管接口。

**理由**：人工配对必然有漏。代管后页面销毁自动回收，消灭 80% 泄漏场景。

**检查**：编译期规则 L-01（CI 门禁）+ conformance C-05

---

### **G-42.4** 容器不得解析 IR / 干预 Diff

> 容器只管**生命周期时机**，不得读取 IR 内容或干预 Diff 结果。

**理由**：职责边界（与 G-41 三方契约一致）。容器解析 IR = 与框架内核耦合。

**检查**：静态扫描（容器实现中不得出现 `semantic` / `diff` 相关判断）

---

### **G-42.5** 超级应用容器必须提供崩溃隔离与配额

> `SuperAppContainer` 必须实现 ≥L1 崩溃隔离，且**业务崩溃后宿主必须存活**。

**理由**：无隔离 = 一个业务崩溃拖垮整个 App。

**检查**：conformance C-07-04 / C-07-05 / C-07-06

---

### **G-42.6** 宿主仓库严禁 fork 框架源码

> 宿主仓库**不得复制/内嵌** Proteus 框架源码。
> 所有定制必须通过：**① 官方扩展点 ② 依赖替换 ③ 组合配置**。

**理由**：fork = 永远升不了级 = 生态碎片化。这是 uni-app / RN 生态的真实写照。

**检查**：静态扫描（源码指纹 + 内部模块 import 检测），CI 门禁

---

## 二、补充规则（CMP059 ~ CMP066）

### **CMP059** 容器策略必须可声明式配置

```typescript
createContainer('superapp', {
  maxDepth: 10,
  sandbox: { defaultMemoryBytes: 128 * 1024 * 1024 },
  crash: { isolationLevel: 2 },
})
```
**禁止**：硬编码在容器实现里。

---

### **CMP060** 深度超限不得静默丢弃

超出 `maxDepth` 时，必须按 `overflowStrategy` 显式处理并发出事件（`overflow-destroyed` / `reject`）。

---

### **CMP061** 配额超限返回 null，禁止静默分配

`quota.request(bytes)` 超限时返回 `null`，**不得**分配并记录警告——静默分配会让配额形同虚设。

---

### **CMP062** 沙箱作用域必须完全隔离

业务沙箱之间**不得共享任何可变全局状态**（scope / storage / router 均独立）。

---

### **CMP063** 崩溃后必须上报宿主

业务崩溃必须触发 `sandbox-crashed` 事件，宿主可观测。**禁止静默吞掉异常**。

---

### **CMP064** 安全网关拒绝而非降级

未签名 / 越权能力 → **拒绝加载**，不是"加载但限制能力"。

---

### **CMP065** 容器必须声明 capabilities

容器必须如实声明 `pageStack` / `multiBusiness` / `crashIsolation` / `resourceQuota` 等能力，不得虚报。

---

### **CMP066** 销毁报告必须可观测

`destroyPage` 必须返回 `DestroyReport`（steps / leaked / reclaimedBytes），供 DevTools 与 CI 消费。
