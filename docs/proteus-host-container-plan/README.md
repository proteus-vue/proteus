## 核心洞察

> **页面栈泄漏的根因是"生命周期没有单一 Owner"。**
> **Proteus 因为有 IR 层，天然拥有这个 Owner——**
> **解法不是"记得清理"，而是"框架代管 + 五原子销毁 + 编译期检测"。**
> **这不是优化，是架构红利。**
