# G-54 铁律

## G-54.1 — 内核唯一

六项能力**只允许一份实现**（FrameworkKnowledgeProvider）。
任何 IDE 适配器不得重新实现业务逻辑。

## G-54.2 — 适配器只做翻译

适配器内**禁止**出现业务判定（如分层规则、断言逻辑）。
违反此条即设计错误——换 IDE 会引入行为分歧。

## G-54.3 — SKIP ≠ FAIL

协议不支持某能力是**预期内**事件，返回 `SKIP` 并降级。
禁止因协议能力缺失而阻断开发流程。

## G-54.4 — 越层必报，豁免显式

分层违规默认必报；任何豁免必须**显式标注 + 理由**，
禁止"静默放行"或"配置里加白名单了事"。

## G-54.5 — 断言必带定位

任何下发给 IDE 的断言失败**必须**含 `file` + `line`。
无定位的断言失败禁止展示（价值远低于噪音）。

## G-54.6 — 循环可检测，不崩溃

依赖图检测到环时返回 `GRAPH_CYCLE` 并列出环路径，
禁止抛异常或无限递归。

## G-54.7 — 不重复 G-19

运行时诊断（trace/timeline/perf）**一律**复用 G-19。
G-54 只做入口跳转，不得重新实现。

## G-54.8 — 数字不虚报

能力覆盖率、IDE 支持数量等对外数字**必须**实测（G-37）。
禁止把"理论上 LSP 支持"当成"已验证支持"。
