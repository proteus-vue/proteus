# G-54 Conformance

## 不变量

| ID | 命题 |
|----|------|
| **INV-DT-01** | 同一请求经不同适配器 → 结果一致（内核唯一性） |
| **INV-DT-02** | 未知能力 → `SKIP`，不崩溃 |
| **INV-DT-03** | 语义导航能定位到后端实现（非文本匹配） |
| **INV-DT-04** | 越层调用必被诊断；显式豁免则不误报 |
| **INV-DT-05** | 断言失败必带 `file`/`line` 定位 |
| **INV-DT-06** | 依赖图能检测循环，返回 `GRAPH_CYCLE` 而非崩溃 |
| **INV-DT-07** | 设备影响面能列出受影响等价类 |
| **INV-DT-08** | 适配器全不可用时，内核仍可调用（降级 raw） |

## 负向用例

| ID | 场景 | 期望 |
|----|------|------|
| NEG-01 | 依赖图存在环 | 返回 `GRAPH_CYCLE`，不崩溃 |
| NEG-02 | 全部适配器不可用 | 降级 raw，内核仍返回结果 |
| NEG-03 | 越层但标注 `@layer-exempt` | 不报违规（防误报） |
| NEG-04 | 查询未知 SPI | 返回 null / SKIP，非异常 |
| NEG-05 | 断言 ID 不存在 | 返回 null，非崩溃 |

## 接缝命题

- **G-51 INV-02（降级不崩溃）∧ G-54 INV-DT-08（适配器全挂仍可用）**
  → 工具链在任何环境下都不会阻断开发
- **G-51/G-52 检查·矩阵报告 ∧ G-54 内联展示** → 反馈周期从分钟级降到毫秒级
