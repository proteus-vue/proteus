# G-54 六项框架独占能力

## ① 语义导航（IR 结构）

**第三方插件做什么**：文本匹配 → `go to definition` 跳到 `.d.ts` 声明
**框架能做什么**：知道 IR 与后端绑定关系

```
开发者点 BackendRegistry.render(...)
   ↓ 第三方：跳到 render 的类型声明（死路）
   ↓ G-54 ：跳到当前激活的后端实现（WebGL / Skia / ArkUI）
```

**价值**：框架知道"当前启用哪个后端"——这是运行时/配置态知识，静态分析拿不到。

## ② 分层守护（SPI 分层规则）

规则：L0（内核）不得直连 L2（平台实现）。

```
L0 ─→ L1 ─→ L2   ✅ 合规
L0 ───────→ L2   ❌ 越层（IDE 实时红线）
```

**为何框架独占**：分层定义写在 G-xx rules.md 里，第三方插件不知道这份规约。
**豁免机制**：显式标注 `@layer-exempt` + 理由，否则必报（防误报与防绕过并重）。

## ③ 断言内联（conformance）

```
conformance 失败：INV-07 隔离泄漏
   ↓ 第三方：只在 CI 日志里看到
   ↓ G-54 ：直接标在 sandbox.cjs:142 行，附修复建议链接
```

**反馈周期**：分钟级 → **毫秒级**。

## ④ SPI 依赖图（拓扑）

与静态 import 图的本质区别：

| | 静态 import 图 | SPI 依赖图 |
|--|--------------|-----------|
| 依据 | 文件 import 语句 | **运行时注册的后端绑定** |
| 能否见动态注册 | ❌ | ✅ |

**能力**：可视化真实依赖 + **循环检测**（返回 `GRAPH_CYCLE`，不崩溃）。

## ⑤ 设备影响面（G-52/53 等价类）

```
开发者改了 webgl.cjs 里一行
   ↓ G-54 提示：影响 3 个等价类
     · 低端 Android（API<28，WebGL 降级路径）
     · iOS 模拟器（无 GPU 加速）
     · 折叠屏（多窗口尺寸变化）
```

**为何框架独占**：等价类清单是 G-53 的产出，外部无从得知。

## ⑥ 多形态预览（G-27 渲染语义）

改一行样式 → 并排显示多个渲染后端下的效果。
**依据**：框架知道每个后端的语义差异表（G-27 conformance）。

## 优先级建议

| 能力 | 实现成本 | 价值 | 建议 |
|------|---------|------|------|
| ② 分层守护 | 低 | 高 | **MVP 首批** |
| ③ 断言内联 | 低 | 高 | **MVP 首批** |
| ① 语义导航 | 中 | 高 | 第二批 |
| ④ 依赖图 | 中 | 中 | 第二批 |
| ⑤ 设备影响面 | 中 | 中 | 第三批（依赖 G-53 数据） |
| ⑥ 多形态预览 | 高 | 高 | 第三批 |

**MVP = ② + ③**：成本最低、反馈最快、且直接减少 code review 往返。
