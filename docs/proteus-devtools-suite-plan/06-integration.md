## 2. 数据流

```
G-51 检查项·断言 ──┐
G-52 矩阵报告   ──┼──→ G-54 内核 ──→ 协议层 ──→ IDE
G-53 等价类     ──┘
```

**G-54 是消费端，不是生产端**——它不产生新的断言/等价类/检查项，
只把已有的东西**搬到开发者眼前**。
