# M4–M8 - Injection / Network / Supply Chain / Runtime / Audit

## M4 - 注入防护（XSS / 脚本注入 / 桥安全）

### Web (XSS)
- **默认转义**：模板插值 `{{ }}` 自动转义（Vue 已内置，铁律：不破坏）
- **禁用 `v-html` / `dangerouslySetInnerHTML`** 除非 `@danger` 显式标注 + 内容经 DOMPurify
- **CSP**：`Content-Security-Policy` 默认 `default-src 'self'`，内联脚本禁用

### 小程序 (脚本注入)
- Skyline 无 DOM，风险在 `eval` / `new Function` / `wx.eval` / `setData` 注入
- `eval` / `Function` 编译期阻断（规则 `no-eval`）
- `setData` 值经白名单 schema 校验（防止 `{"__proto__": {...}}` 污染）

### App (桥安全)
- JSBridge 消息加签名 + 来源校验（仅信任原生端）
- 消息 payload JSON schema 校验，拒绝未知字段
- 原生 → JS 方向：白名单 action 枚举

### 编译期禁用 API 清单
```ts
const BANNED = [
  'eval', 'Function', 'setTimeout(string)', 'setInterval(string)',
```

## M5 - 网络安全（HTTPS / TLS Pinning / 脱敏）

- **强制 HTTPS**（生产）：`createRequest({ baseURL })` 自动 reject `http://`
- **证书固定（可选）**：`certPinning: true` → 内置公钥 hash，握手校验失败断开
- **请求/响应脱敏**：`redact: ['Authorization', 'password', 'idCard']` → 日志/trace 替换为 `***`
- **防重放**：对接 M2 的 nonce + timestamp
- **CORS / 跨域**：Web 默认 `credentials: 'include'` + 服务端白名单 origin

## M6 - 供应链安全（对接 Build M7.6）

- **SBOM 生成**：构建期输出 `sbom.json`（CycloneDX / SPDX）
- **漏洞扫描**：`osv-scanner` / `npm audit` 接入 CI，高危阻断
- **依赖锁定**：`pnpm-lock.yaml` + 完整性校验（自带）
- **产物签名**：`proteus build` 输出 `manifest.json` + SHA256，CI 验证
- **私有包白名单**：只允许 `@proteus-vue/*` + 已批准 registry

## M7 - 运行时隔离（CSP / 沙箱 / WebView）

- **CSP + Trusted Types**（Web）：阻断 DOM 注入型 XSS
- **iframe 沙箱**：第三方内容强制 `sandbox="allow-scripts"` + 隔离 origin
- **WebView 隔离（小程序）**：`web-view` 的 src 白名单（`<web-view src>` 仅允许配置域名）
- **Worker 隔离**：不可信计算放 Web Worker，主线程不暴露
- **内存/句柄清理**：对接 Lifecycle `onDestroy` 清理定时器/连接

### 规则集配置
```ts

  },
```

## 迁移指南

1. 安装 `@proteus-vue/security`
2. 替换 `localStorage.setItem('token')` → `useAuth().login()`
3. 替换 `wx.authorize` → `defineCapability + withPermission`
4. 替换 `v-html` → `<SafeHtml :html>`（DOMPurify 包装）
5. 运行 `proteus audit security --fix` 自动升级漏洞依赖
6. CI 接入 `audit security` 门禁
