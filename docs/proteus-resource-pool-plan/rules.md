# G-46 铁律（rules）

## 框架铁律

| 编号 | 规则 | 级别 |
|------|------|------|
| G-46.1 | 页面**必须**经 ResourceFacade 取登录态，**禁止**直读 Cookie | error |
| G-46.2 | **禁止**绕过双轨桥接手写平台分支（`if (isIOS) ...`） | error（PRIM 同源） |
| G-46.3 | **禁止**绕过网关直调 PlatformBackend | error（RND 同源） |
| G-46.4 | 登录态**必须**走 Rc/Weak 所有权，页面销毁**必须**归还 | error |
| G-46.5 | logout() **必须**级联清理 L1→L2→L3 + 跨页引用 | error |
| G-46.6 | PlatformBackend **必须**通过 conformance（CMP089-096）方可接入 | error |
| G-46.7 | **禁止**用 localStorage / 全局变量存 Token（无 TTL/吊销） | error |
| G-46.8 | 动态资源模块**必须**同签名链 + manifest 哈希校验 | error（G-45 同源） |

## CMP 映射

```
CMP089 ~ CMP096  →  RSC-01 ~ RSC-05（见 05-security.md）
```

## 全局编号对齐说明

**正式编号**：本包 = **G-46** —— 原则 #0「不绑定」第 10 次泛化（不绑定资源容器形态）。本批 G-46~G-52 统一入库，编号以 facade G 表为准（决策 #385）。

**与既有 G 表对齐**：G-27（渲染后端）、G-39（宿主运行时 host-runtime）、G-42（宿主容器 host-container/安全网关）、G-43（资源所有权 ownership）、G-44（测试 IR/统一 runner）、G-45（动态装载/签名同源）。本包 CMP089-096 位于全库连续段，无冲突。

**这是 G-45 已暴露的教训**：编号须在入库时一次性对齐，避免同一套件内部编号与全局编号两份并存。
