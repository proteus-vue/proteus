## 已知缺口

| 缺口 | 说明 |
|------|------|
| **激活耗时测量** | 本份用声明的 cost 估算，非真实执行计时 |
| **tier 映射完整性** | 只登记了代表性 API，真实环境需完整枚举 |
| **破坏率基准** | 无真实版本历史，无法给出"多少算合格" |
| **生态吸引力** | 架构无法解决冷启动的鸡生蛋问题 |

## 与 G-58 的关系处理

G-58 的 capability 模型**不推翻**，升级为：
```
capabilities.has(api)  →  grantedTiers.has(tierOf(api))
```
G-58 的 `skipped` / `denied` 语义保留，G-59 新增 `reauth-required` 态。
