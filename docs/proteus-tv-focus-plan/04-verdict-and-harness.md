## 2. ★装置修正一：`adb input keyevent` **造不出长按 repeat**

### 2.1 事实

- `adb shell input keyevent 22` = 一次完整 **down + up**，`KeyEvent.getRepeatCount()` **恒 0**。
- ⇒ 「长按重复 10+ 次/秒」这条**用 adb 结构上产生不了**，无论注入多少次。

### 2.2 两个合法装置（择一，报告须写明用的是哪个）

| 装置 | 做法 | 能验证 | **不能**验证 |
|---|---|---|---|
| **A · 离散快按** | 脚本连续注入 N 次 keyevent（间隔可调） | 焦点算法、渲染、滚动跟随、事件吞吐 | **repeat 语义**（恒 false） |
| **B · 宿主 dev 合成** | 宿主加 `--proteus-key-repeat=N`（仅 dev）：按住时按 `repeatInterval` 发 `repeat=true` | repeat 路径、限速、业务加速 | 真实遥控时序（合成间隔是理想值） |

**默认选 A**（零侵入）；只有需要验证 repeat 时才开 B，且**必须同时跑 A 作对照**。

### 2.3 报告措辞纪律

| ❌ 禁止 | ✅ 允许 |
|---|---|
| 「长按重复 10 次/秒已验证」 | 「离散注入 60 次，间隔 16ms；**repeat 语义未覆盖**（见装置 A）」 |
| 「遥控长按性能达标」 | 「repeat=false 路径 P95 = X ms；repeat=true 路径用装置 B 测得 Y ms」 |

## 3. ★装置修正二：长任务必须**先归因到 JS / 宿主**

### 3.1 为什么必须拆

已有实测（iPhone 12，决策 #1099/#1100/#1105）：

| 项 | 数值 | 层 |
|---|---|---|
| JS 同步段（`eval` 内） | **~3ms** | JS |
| mount 总 | 30–93ms | **宿主 native** |
| 玻璃遍（稳态） | 5.2ms | 宿主 native |

⇒ 在 1.5–2GB 盒子上，`P95 < 20ms` 这类阈值**大概率被宿主 native 吃掉**。
若不拆，就会把宿主的账记到 JS 头上，进而误判"要上 JS 时间片"——**这正是 #1099 花一整轮才纠正的错误**。

### 3.2 分栏要求（P5 的正式形态）

| 栏位 | 读数来源 | 已存在 |
|---|---|---|
| `js_sync_p95_ms` / `js_long_count` | `JsTaskSampler`（Android/iOS 9 字段同名） | ✅ #1098 |
| `host_mount_ms` + `mount_{measure,layout,wrap,emit,scroll}_ms` | mount 相位读数 | ✅ #1100/#1101 |
| `key_to_focus_ms`（按键→焦点变更） | 新增打点（B2） | ⬜ 待建 |
| `focus_to_paint_ms`（焦点变更→下一帧呈现） | 宿主帧统计（Choreographer/CADisplayLink 已有） | ✅ 部分 |
| `glass_pass_ms`（若该屏有玻璃） | 玻璃相位 | ✅ #1101 |

**判定顺序（不得跳）**：① 看 `key_to_focus_ms` 占比 → ② 若大头在 `focus_to_paint_ms`，查渲染 → ③
若 `host_mount_ms` 大，属首屏一次性成本（**不算稳态**） → ④ 只有 `js_sync_p95_ms` 真的高，才谈执行原语。

## 4. 装置自检（跑前 5 秒，零成本）

> 依据本仓 Android acceptance 的三道预检纪律（产物契约 / 解析自测 / 设备状态）。

| # | 检查 | 判法 |
|---|---|---|
| S1 | 产物契约 | 报告里必须同时出现 `key_events_received` 与 `focus_sequence`；缺一个即**装置失败** |
| S2 | 通道自检 | 注入 1 次 `right` ⇒ `key_events_received` 必须 +1；否则判装置而非框架 |
| S3 | 几何来源 | 每个 focus rect 带 `source:'kernel'`（App）/ `'dom'`（Web）；宿主自算的几何直接判红 |
| S4 | 设备状态 | 盒子屏幕亮、分辨率/刷新率已记录（P5 阈值依赖刷新率） |
| S5 | 版本指纹 | 宿主 ABI 版本 + bundle build_id 必须与本轮一致（防旧包冒充） |
