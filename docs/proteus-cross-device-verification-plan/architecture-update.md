# 架构更新（G-52）

## 新增原则

- **#13.54** 跨设备一致性：验证必须跨越设备形态
- **#13.55** 不绑定设备形态：同一 TestSuite 跨设备可比对
- **#13.56** 基线可复现：等价类 + ε 版本化

## 成熟度模型更新

```
L0 文档自检       ← G-50
L1 IR 模拟        ← G-51
L2 真运行时       ← G-51 + G-52(设备矩阵)
L3 跨设备(云端)   ← G-52 (接口定义，调度留 G-53)
L4 开放生态       ← G-50 (依赖 G-49 L3)
L5 开发者门户     ← G-50
L6 治理与分佣     ← G-50
```

G-52 将「跨设备」推至 L2 入口，L3 仅剩云端调度。

## 与既有体系互校

- **G-51** `TestIRRunner.execute()` → G-52 `executeOn()`（同构扩展）
- **G-49** ISOLATION_BREACH → G-52 跨进程指纹归因
- **G-48** 运行时能力 → 设备矩阵的执行后端
- **G-46** 数据一致 → 等价类去噪后比对

## 已知缺口

- 真实设备 profile 数据库（运营数据）
- 云端真机调度（ProfileSource 真实现）
- 视觉回归 diff（截图比对，属 G-53+）
