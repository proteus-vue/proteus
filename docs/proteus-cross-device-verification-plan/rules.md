# G-52 铁律

## G-52.1 — 等价类覆盖优先

不穷举设备，**等价类 + 代表采样**是唯一可扩展策略。

## G-52.2 — 允许偏差，用 ε 阈值

渲染/触摸天然有浮动。`DRIFT_EXCEEDED` 判定**必须**用 ε 比对，禁止 `===`。

## G-52.3 — FAIL 必归因到四维

任何跨设备漂移 **必须**通过 `DriftFingerprint` 定位到 screen/os/input/env 之一。

## G-52.4 — 归一化结果可 diff

矩阵报告 **必须** 可 JSON 序列化、可 diff，作为 CI 门槛。

## G-52.5 — 本地优先

核心验证 **不依赖** 云端真机。`ProfileSource` 是按需补充，非必需。

## G-52.6 — 基线可复现

等价类定义 + ε 阈值 **必须** 版本化，保证 INV-D1 幂等。

## 反模式

- **AP-22** 穷举设备矩阵 → 组合爆炸
- **AP-23** 浮点 `===` → 误报
- **AP-24** 强制联网 → 违背 G-52.5
- **AP-25** 无代表采样 → 等价类失效
