# 铁律与补充规则（G-41）

> 编号段：`G-41.1`–`G-41.6`、`CMP051`–`CMP058`
> **编号避让声明**：G-40 占用 `G-40.1`–`G-40.6` 与 `CMP044`–`CMP050`；本文件从 `G-41.1` / `CMP051` 起编，零冲突。

---

## 铁律（G-41.x）

| 编号 | 条文 | 机器可检查 | 出处 |
|------|------|-----------|------|
| **G-41.1** | 框架**不得**直接创建线程、访问原生 View、调用平台 SDK | ✅ 静态扫描（H-04-03） | 原则 #0 支柱② |
| **G-41.2** | 宿主**不得**解析 IR、干预 Diff、决定渲染方式 | ✅ 静态扫描（H-04-05） | 原则 #0 支柱② |
| **G-41.3** | 引擎**不得**感知 Vue、响应式、SFC 的存在 | ✅ 静态扫描（H-04-04） | 原则 #0 支柱① |
| **G-41.4** | 业务代码**不得**出现平台判断或原生 SDK 直接调用 | ✅ 编译期 | G-28.1 / G-31.1 |
| **G-41.5** | 业务代码**不得**假设 JS 运行时存在 | ✅ 静态扫描 | G-40.1 |
| **G-41.6** | 宿主**必须**在 bootstrap 前完成 Runtime + Carrier + Backend 注册，且通过 host-conformance | ✅ 运行期（H-01-04） | 原则 #11 |

**六条铁律的共同本质**：把"三方正交"从设计意图变成可执行的架构约束。

---

## 补充规则（CMP051–CMP058）

| 编号 | 条文 |
|------|------|
| **CMP051** | 宿主必须在 `bootstrap()` 之前完成 Runtime / Carrier / Backend / Capability 全部注册 |
| **CMP052** | 业务代码禁止直接引用 `RenderBackend` 或 `nodeOps` |
| **CMP053** | 业务代码禁止直接调用 `HostRuntime.createWorker` / `invokeNative` |
| **CMP054** | 引擎实现中禁止出现 `vue` / `@vue/*` 的 import |
| **CMP055** | 框架代码中禁止出现平台 SDK import（`UIKit` / `android.*` / `@ohos.*`） |
| **CMP056** | 宿主代码中禁止出现 IR 字段名（`semantic` / `ComponentIRNode`）的分支判断 |
| **CMP057** | 引擎切换后必须触发 conformance H-05 热切换验证 |
| **CMP058** | 宿主上线前必须满足 `HostConformance.run(app).failed === 0` |

## 违反后果

| 违反 | 后果 |
|------|------|
| G-41.1（框架碰原生） | 跨端性丧失，新端接入需改框架 |
| G-41.2（宿主解析 IR） | 引擎不可替换，插拔架构失效 |
| G-41.3（引擎感知 Vue） | 引擎与框架耦合，无法独立演进 |
| G-41.4（业务写平台判断） | "一套代码"失效，退化为 uni-app |
| G-41.5（业务假设 JS） | AOT 路径不可切换（G-40 失效） |
| G-41.6（注册顺序错） | 运行期行为未定义 |
