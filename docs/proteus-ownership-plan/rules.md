# G-43 铁律与补充规则

> **编号避让**：G-42 使用 G-42.1-6 + CMP059-066；G-43 使用 **G-43.1-6 + CMP067-073**，零冲突。

---

## 一、铁律（G-43.x）

### **G-43.1** 边界资源必须归属某个 Owner，禁止无主资源

**说明**：任何 GC 管不到的资源（原生句柄、共享内存、定时器、订阅、流），
必须在创建时登记到所有权图并指定 Owner。

**违反后果**：无主资源 = 必然泄漏，且 DevTools 无法定位。

**检查**：所有权图中 `owner === null` 的节点数必须为 0（V-05）。

---

### **G-43.2** Move 后原所有者不得再访问

**说明**：`transferTo()` 之后，原 `Owned<T>` 状态变为 `moved`，
任何 read/write 必须被拦截。

**分层保证**：
- PSS strict：编译期报错（G4001）
- PSS loose：主路径分析
- PSS off：运行时抛 `UseAfterMoveError`

---

### **G-43.3** 借用不得逃逸其作用域

**说明**：`Borrow<T>` 的引用只能出现在其创建作用域内。
存入全局、跨页面 store、或被闭包捕获，均为逃逸。

**分层保证**：
- PSS strict：编译期报错（G4003）
- 其余：DevTools 长期借用告警

---

### **G-43.4** 默认路径框架代管，业务零心智负担

**说明**：99% 场景（定时器、订阅、请求）走 `Managed<T>`，
由框架在页面销毁时自动释放。业务代码**不需要写释放逻辑**。

**理由**：传统泄漏的主要来源就是"申请和释放分离"。
框架代管让释放动作不在业务代码里 → 业务代码里没有"忘记"的机会。

---

### **G-43.5** 所有权关系必须 100% 可观测

**说明**：所有权图必须维护 Owner / Borrow / Weak 关系 + 源码位置 + 生命周期。
DevTools 必须能展示完整图和泄漏路径。

**理由**：这是「出问题好排查」痛点的直接解法。
只有堆快照（可达性）不够，必须有所有权（意图）。

---

### **G-43.6** 确定性 Drop，禁止依赖 GC 时机

**说明**：边界资源的释放必须是确定性的 —— 业务调用 `drop()`，
或作用域结束（PSS strict 编译期插入），或页面销毁（强制回收）。
**不得**依赖 GC 回收。

**理由**：GC 时机不确定 → 配额被长期占用、文件句柄耗尽、内存曲线无法解释。

---

## 二、补充规则（CMP067-073）

### **CMP067** 禁止在业务代码中直接释放框架代管的资源

❌ `pageContext.timer(...)` 后手动 `clearInterval`
✅ 由框架在页面销毁时释放；需要提前释放时用 `.dispose()`

---

### **CMP068** 跨设备转移必须是原子的

```
要么：原端 drop + 目标端接管
要么：原端保留所有权 + 返回 error
禁止：中间态（两端都有 / 两端都没有）
```

---

### **CMP069** 不可转移资源必须显式拒绝，禁止静默降级

❌ 摄像头句柄跨设备转移时"复制一份"（语义错误）
✅ 返回 `resource_not_transferable` + 原因

---

### **CMP070** 释放失败必须可观测，禁止静默

❌ 捕获异常后继续，资源标记为 dropped
✅ 返回 `Result<T>`，节点保持 alive，上报 DevTools

---

### **CMP071** `Owned<T>` 默认禁止被 `ref` / `reactive` 包装

**原因**：Vue 的 Proxy 会干扰所有权状态追踪，
且代理产生的额外引用会污染所有权图。

**替代**：`useOwned()` 提供响应式的**元信息**（state / byteSize），
不暴露实际资源引用。

---

### **CMP072** PSS strict 模块禁止引入未声明 PSS 的第三方库

**原因**：第三方库的动态特性会破坏静态分析的可判定性。

**处理**：白名单机制 + `// @proteus-pss-ignore` 显式豁免（并计入可观测）。

---

### **CMP073** 配额记账必须与所有权图一致

**原因**：配额（G-39/G-42）依赖准确的资源账目。
所有权图少记一个节点 = 配额虚高 = 内存超限。

**检查**：`QuotaTracker.used(scope)` 应等于该 scope 所有存活节点 byteSize 之和。
