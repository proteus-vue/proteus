<!-- 一份 SFC，全端通用 -->
<p-adaptive
  :breakpoints="[0,640,1024]"
  :cols="{mobile:1,tablet:2,desktop:3}"
  nav="auto"
  input="contextual">

  <p-app-header :title="store.name" />

  <p-grid
    :min-col-width="180"
    :max-cols="cols"
    :gap="dense?8:16">
    <p-card v-for="item in items" />
  </p-grid>

  <p-fab v-if="touch" />
  <p-sidebar v-if="wide" />

</p-adaptive>
设计契约
// 开发者只描述"意图"
cols   → 语义：列数随形态变
gap    → 语义：间距随密度变
nav    → auto：端自行决策
input  → contextual：
          touch / mouse / dpad / crown
v-if   → 能力/形态守卫
渲染呈现 · 随端而变 实时联动

Backend 决策（IR 落地）
切换上方任一终端 → 源码零改动，RenderBackend 重算布局拓扑。 p-adaptive 的 breakpoints 是语义约束，不是 CSS 媒体查询—— 车机 / TV 的断点由 input（dpad / 遥控器）与 usage-distance（10ft）触发，而非屏幕像素。

● 绿色能力 = 该 Backend 已声明支持  ·  ● 橙色 = 需 @conditional 降级（如手表无 FAB、车机无侧栏）
