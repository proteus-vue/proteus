# 严格规则（G-32）

> 铁律 + 严格规则。任何违反必须修复，CI 门禁拦截。

---

## 1. 铁律（Must Not Violate）

### G-32.1 覆盖率 100%
> L1 原语必须覆盖小程序官方能力的 **100%**（组件 + API 类别），`audit:coverage` 输出必须 = 100.00%。

**触发**：CI 构建阶段  
**修复**：补齐缺失原语（L1 或显式标记 ⬛ private）  
**例外**：无

### G-32.2 禁止与小程序组件同名
> L1 原语 **禁止** 使用小程序组件名（`view` / `scroll-view` / `swiper` / `movable-view` 等）。同名必须走 `@proteus/compat-miniprogram`。

**理由**：避免「以为是小程序兼容，其实是 Proteus 语义」的混淆。`<p-box>` 是语义，`<view>` 是小程序别名——必须区分。

**触发**：lint（`proteus/lint:primitives`）  
**修复**：重命名为 `<p-*>` 语义名

### G-32.3 三端实现
> L1 能力原语必须 **至少 3 端实现**（Web / iOS / Android 至少三），鸿蒙 / 小程序 / 车机可选。

**触发**：conformance test  
**修复**：补齐 Backend 实现，或降级为 L2  
**例外**：平台私有能力（⬛）标记后豁免

### G-32.4 禁止回调风格
> 所有能力原语 **必须** 返回 `Result<T>` 或 `Promise<T>`，**禁止** 回调风格（`success/fail/complete`）。

**对照**：
```ts
// ❌ 禁止
wx.request({ url, success: (res) => {}, fail: () => {} })

// ✅ 必须
const { data } = await useFetch(url).execute()
```

**触发**：lint + 类型检查  
**理由**：回调无法组合、无法 await、与 Vue 响应式割裂

### G-32.5 属性即约束
> 原语属性 **必须** 描述「我要什么布局/行为」，禁止暴露 CSS 属性名（`display` / `flex-direction`）或平台 API 名（`scroll-x` / `enable-flex`）。

**对照**：
```vue
<!-- ❌ 禁止 -->
<p-view flex-direction="row" scroll-x>

<!-- ✅ 必须 -->
<p-stack direction="row">
```

**触发**：lint  
**理由**：属性暴露实现细节 → Backend 无法自由选择实现 → 退化成翻译层

## 2. 严格规则（Should Not Violate）

### CMP009 组合性审查
> 新增原语须经 **组合性审查**：若能用现有原语组合表达，不得新增。

**流程**：
```
提案新原语 <p-xxx>
   ↓
1. 检查能否用 [布局原语 + 能力原语 + 插槽] 组合
   ↓ 能 → 拒绝新增，提供组合方案
   ↓ 不能
2. RFC 说明「为什么不可组合」
   ↓
3. TC 评审（2 票通过）
   ↓
4. 冻结进 registry + 更新对照矩阵
```

**示例**：
- ❌ `<p-swiper>` → 可用 `<p-stack snap="mandatory" loop>` 表达 → **拒绝**
- ✅ `<p-draggable>` → 无法用布局+能力组合（需手势识别器）→ **接受**

### CMP010 语义命名
> 原语名 **必须** 表达意图，禁止技术实现词。

**允许**：`grid` / `stack` / `virtual-list` / `media`  
**禁止**：`flex-container` / `css-grid` / `webview-wrapper` / `div-like`

### CMP011 类型完备
> 所有原语属性、能力返回值 **必须** 有完整 TS 类型，禁止 `any`。

**触发**：`tsc --strict` + 自定义规则  
**理由**：类型即文档，IDE 自动补全 = 开发者体验

### CMP012 版本稳定
> L1 原语 API **冻结后不破坏**（minor 版本内）。新增属性必须可选（默认保留旧行为）。

**理由**：128 原语是公共契约，破坏 = 生态碎片化

```markdown

- [ ] **G-32.3** 至少 3 端实现（或明确降级计划）
- [ ] **G-32.4** 无回调风格
- [ ] **G-32.5** 属性为约束（无 CSS/平台 API 名）
- [ ] **CMP009** 组合性审查通过（附「为什么不可组合」说明）
- [ ] **CMP010** 语义命名
- [ ] **CMP011** 类型完备（无 `any`）
- [ ] **CMP012** API 向后兼容（或标注 breaking change）

- [ ] conformance 测试已添加
- [ ] 文档已更新（本目录 + API 文档）
```
