# G-57 铁律

## G-57.1 — 叠加，不替代

**绝不重新实现运行时探针。** L0 用宿主/系统已有的（VM Service / Flipper / CDP）。
G-57 只做语义叠加。

> 违反后果：重复造轮子，且与团队既有工具链分裂。

## G-57.2 — L1/L2 只能增益，不能减损

**L1/L2 的任何失效都不得影响 L0。**
降级返回未标注数据或 null，**绝不抛异常、绝不阻断**。

## G-57.3 — 扩展命名必须合规

`ext.<package>.<command>`，**拒绝**任何不合规命名。
命名冲突在注册期暴露，**不留到运行时**。

## G-57.4 — Release 编译期剔除

不是运行时判断，是**编译期不存在**。
CI 必须扫描 Release 包，`ext.proteus.*` **零命中**。

## G-57.5 — localhost 优先 + 一次性 token

局域网暴露需**显式 opt-in**。
**绝不**无鉴权暴露到网络。

## G-57.6 — 绝不采集用户数据

上报的是**框架自己的健康度**，不是用户行为。
任何 PII 进入上报通道 = 严重违规。

## G-57.7 — 覆盖率不粉饰

空样本覆盖率 = **0**，不是 1。
覆盖率低时如实显示，**不允许用默认值填充**。

## G-57.8 — 不绑定可观测性来源

L0 从哪来无所谓（VM Service / Flipper / 自起服务 / 系统 API），
数据模型统一。**换宿主不改 Inspector。**

## 反模式

- **AP-INSP-01** 重新实现内存/CPU 探针 → 违反 G-57.1
- **AP-INSP-02** L1 缺失时抛异常 → 违反 G-57.2
- **AP-INSP-03** 用简短扩展名（`ext.foo`）→ 包间冲突
- **AP-INSP-04** Release 靠运行时 if 关闭 → 代码仍在包里，可逆向触发
- **AP-INSP-05** 无鉴权暴露局域网 → 架构图外泄
- **AP-INSP-06** 上报用户行为数据 → App Store 必拒
- **AP-INSP-07** 空样本算作 100% 覆盖率 → 指标失去意义
