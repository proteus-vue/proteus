Layout Primitive · G-32

One semantic model.
<p-grid> 多后端剖面

二维网格布局，按 min-col-width 自动分列。同一份语义，由四层渲染后端各自实现。

语义定义

<p-grid> 属性与 IR 约束

min-col-width（必填，>0）· max-cols（≥1）· gap · auto-rows

IR 约束：min-col-width > 0；max-cols ≥ 1；冲突 → 编译期报错（G-32 支柱③）。

● 多后端实现剖面

同一语义，五端实现（W-2 可视化证据）

iOS → UICollectionViewCompositionalLayout
Android → GridLayoutManager / LazyLayout
Flutter → GridView.builder
Skia → 几何计算 + SkCanvas::drawRect
VueDom → CSS Grid: repeat(auto-fit, minmax(160px,1fr))
降级 · Tier 2/3

@conditional：后端不支持 grid 时

自动降级为 <p-stack> 单列（G-30 capabilities 声明）。开发者代码零修改。
