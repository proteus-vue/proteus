01 · 语义优先

    
组件即语义，不是 div 别名

    
<p-grid> 表达「网格意图」，属性是约束描述。swiper / scroll-view / movable-view 被还原为布局属性组合——不再有独立组件。

  

  

    
02 · 四层 SPI

    
编译 · UI · 能力 · 端，全部可插拔

    
Node 遇瓶颈一键切 Rust/WASM；渲染换 Native/Flutter/Skia；原生能力走 JSI；任意端实现 Backend 即一等公民。

  

  

    
03 · 证明先于宣称

    
conformance test，编译期拦截

    
能力缺失不是运行时崩溃，是编译期报错。三端 Backend 对同份 IR 必须产出等价结果，CI 自动校验。

  







  
与「翻译派」的本质分水岭

  
传统框架把小程序 API 当标准去翻译；Proteus 定义自己的语义 IR，各端来实现。
