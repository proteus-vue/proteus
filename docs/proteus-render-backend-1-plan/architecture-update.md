# Architecture 规约更新（G-27）

## 新增模块

- **G-27 可插拔渲染后端架构**（基础设施层）

## 原则泛化

- **原则 #10** 从"统一语义 + 原生实现"泛化为"**统一语义 + 后端实现**"——原生能力是后端的一种。

## 铁律（新增）

- **RND001**：禁止业务直调后端专有 API；走 `p-*` 或 Backend SPI
- **RND002**：后端必须通过 `backend-conformance-test`
- **RND003**：布局语义不得硬编码为某后端算法
- **RND004**：混合后端须声明纹理/事件边界
- **RND005**：后端不得在 IR 层外修改组件树
