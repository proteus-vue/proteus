# G-56 铁律

> 九条铁律。其中 **G-56.1 是红线，无例外、无降级**。

---

## 铁律

### G-56.1 — 禁止自研编辑器内核与 GUI 框架（红线）

```
禁止：编辑器内核、GUI 框架、终端模拟器、解码器
允许：面板 UI、编排层、宿主壳（基于 Web 技术栈）
```

**依据**：xi-editor 已死、Lapce 至今 pre-alpha、Floem 两年未发新版（IME 不可用、无障碍不可用）。

**这条不给降级路径**——一旦越过，项目进入死亡螺旋。
任何触碰此线的提案，无论收益多大，一律否决。

---

### G-56.2 — 自有宿主不享有内核特权

Studio 与 VSCode / IntelliJ / Zed 使用**完全相同**的内核接口。

> **加自有宿主时若被迫改内核，说明三层分层没做对。**

自有宿主最容易产生"开后门"的诱惑——**恰恰是这种情形最能验证分层真伪。**

---

### G-56.3 — 设备输入坐标必须归一化 0..1

`DeviceBridge` 适配层**必须**校验并拒绝像素坐标。

> 传像素坐标，换分辨率后全错。serve-sim 强制 0..1，这不是风格问题是正确性要求。

---

### G-56.4 — 平台风险如实上报，禁止乐观默认

`probeRenderBackend()` 返回 `unknown` 时，**必须**如实上报，**禁止**默认当作 `'hw'`。

> **你无法验证的性能，不叫性能。**（G-37 在平台探测上的应用）

---

### G-56.5 — Linux 默认降级到 Web 版

除非通过实测白名单，Linux 档一律降级。

```
NVIDIA → web
WebKitGTK 版本不匹配 → web
renderBackend = sw / unknown → web
```

宁可让用户用功能完整的 Web 版，也不赌无法验证的原生体验。

---

### G-56.6 — 嵌入失败降级，永不崩溃

五档降级链每一档返回 `DEGRADED` + 原因，**不判 FAIL、不阻断 CI**。

延续 G-51 INV-02「能力缺失 → 降级 ≠ 崩溃」。

---

### G-56.7 — 无障碍树优先于截图比对

跨设备视觉断言**必须**基于 AX 树，禁止以截图像素比对作为主判据。

> 截图比对在字体渲染、暗色模式、折叠屏下必然误报。

---

### G-56.8 — 数字不虚报

Tauri 的 3.2MB / 380ms / 42MB 是**框架级 benchmark，非 Proteus 实测**。
conformance 用例数**以实测为准**，文档与实测不符时改文档。

延续 G-54.8 / G-55.7 纪律。

### G-56.9 — 生态边界诚实标注，不追求 VSCode 扩展兼容

Studio **不兼容** `.vsix`，**不使用**官方 Marketplace（许可禁止）。语言智能走 **LSP/DAP**（开源可分发）。

> **闭源专有扩展（Pylance / C# Dev Kit 等）的损失必须对外明说**，不得用"兼容性良好"含糊带过。

**依据**（详见 `07-ecosystem-compat.md`）：
- 技术：VSCode 扩展依赖 Node 运行时 + 宿主注入的 `vscode` 模块，Tauri 三样皆无
- 许可：官方 Marketplace 仅授权 Microsoft 官方发行版
- 架构：为一个不需要的能力付全部代价，同"不 fork VSCode"的逻辑

**插件生态自建已入库为 G-58**（proteus-plugin-api-plan，#395——原稿预留 G-59 号作废，按当时连续段位定号）。

## 反模式（AP-ST-01 ~ AP-ST-08）

| ID | 反模式 | 后果 |
|----|--------|------|
| **AP-ST-01** | 自研编辑器内核"因为想要更好体验" | 项目死亡（xi/Lapce 实证） |
| **AP-ST-02** | 自研 GUI 框架 | 同上（Floem 两年未发新版） |
| **AP-ST-03** | 给自用宿主开内核后门 | 分层失效，三宿主行为分歧 |
| **AP-ST-04** | 传像素坐标给设备输入 | 换分辨率全错 |
| **AP-ST-05** | `unknown` 当作 `hw` | 静默降级到软件渲染而不自知 |
| **AP-ST-06** | 截图比对做跨设备断言 | 必然 flaky |
| **AP-ST-07** | 宣称未实测的性能数字 | 违反 G-37 |
| **AP-ST-08** | 嵌入 code-server 假装"兼容 VSCode 生态" | 回到 Electron 天花板，且违反 G-56.1 精神（假自研） |
