# M7 超级应用加固（Compiler 层）

> 对齐整体 M7 "超级应用可靠性"：编译期兜底，让运行时更稳。

## 一、循环依赖检测

依赖图（M6）构建时检测环：

```
A → B → C → A  ✘ 报错并列出环路径
```

阻断构建，不静默（模块循环会导致初始化顺序不确定）。

## 二、产物体积预算

每端产物分块设上限：

| 端 | 预算 |
|----|------|
| Web 首屏 JS | < 200KB gzip |
| Skyline 主包 | < 2MB（小程序主包限制内） |
| Skyline 分包 | < 2MB/包 |
| App 首帧资源 | < 1MB |

超限则报错 + 提示优化方向（分包、懒加载、按需引入）。

## 三、死代码消除

- Tree-shaking：未使用的组件/工具/store 不进产物
- 平台分支消除：`if (platform === 'web')` 在 codegen 期常量折叠
- 副作用标记：`package.json` `sideEffects` 配置校验

## 四、兼容性降级检查

- Skyline 不支持的 CSS/API 在编译期**警告 + 自动降级**（如 `position:fixed → absolute`）
- 降级清单可配置，默认严格模式（`strict: true` 时降级即报错）

## 五、确定性构建

- 产物内容仅由源码决定（无随机 hash、无时间戳）
- 相同输入 → 相同输出（便于缓存 + CI 比对）
- hash 用于文件名缓存（如 `app.[hash].js`），但内容稳定

## 六、资源清理

- 未引用的静态资源（图片/字体）不进产物
- 产物中孤立文件检测（无引用入口）

## 七、验收

- [ ] 循环依赖被检出并阻断
- [ ] 体积预算超限有明确提示
- [ ] 产物 deterministic（重复构建字节一致）
- [ ] Skyline 不兼容写法被检测并降级/报错
