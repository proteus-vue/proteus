# 02 - IR（中间表示）

## 目标

定义**平台无关**的中间表示，作为 Parse 与 Codegen 之间的契约层。

> 铁律：IR 节点不带任何平台 API（`wx.*` / `document.*` / `UIView`）。所有平台差异收敛在 codegen。

## IR 节点总览

```
IRProgram
 ├─ ComponentIR     (一个 .vue 组件)
 ├─ RouteIR         (一个 <route> 块，Router M2)
 ├─ BindingIR       (一个响应式绑定，Pinia Vapor)
 ├─ ModuleIR        (一个业务模块，Module M1)
 ├─ StoreIR         (一个 Pinia store)
 ├─ CapabilityIR    (一个平台能力，Platform M1)
 └─ AssetIR         (静态资源)
```

## 核心：ComponentIR

```ts
interface ComponentIR {
  type: 'Component'
  id: string                    // 组件唯一 id（路径哈希）
  tag: string                   // 模板根标签（view/scroll-view/...）
  props: PropDef[]              // 对外 props
  emits: string[]               // 对外事件
  slots: SlotDef[]              // 插槽定义
  template: IRNode              // 模板 IR 树
  bindings: BindingIR[]         // 响应式绑定（Vapor）
  styles: StyleIR[]             // 样式 IR
  dependencies: string[]        // 依赖的组件/模块 id
  meta: RouteIR | ConfigMeta    // 附加元信息
  loc: SourceLocation
}

interface IRNode {
  type: NodeType                // 'Element' | 'Text' | 'Interpolation' | 'For' | 'If' ...
  tag?: string
  props?: IRProp[]
  children?: IRNode[]
  // ... 平台无关语义
}
```

## 示例：SFC → ComponentIR

```vue
<!-- 输入 -->
<template>
  <view v-if="show" :class="{ active }" @click="onClick">
    {{ title }}
  </view>
</template>
```

```ts
// 输出（简化）
{
  type: 'Component',
  tag: 'view',
  template: {
    type: 'Element',
    tag: 'view',
    props: [
      { type: 'Directive', name: 'if', expr: 'show' },
      { type: 'Directive', bind: 'class', expr: '{ active }' },
      { type: 'Event', name: 'click', handler: 'onClick' },
    ],
    children: [
      { type: 'Interpolation', expr: 'title' },
    ],
  },
}
```

## RouteIR（对接 Router 计划）

```ts
interface RouteIR {
  type: 'Route'
  path: string
  name?: string
  component: string              // 组件 id
  parent?: string                // 嵌套父级 id（由 path 推导）
  meta: {
    title?: string
    transition?: TransitionType  // slideUp / halfScreen / scaleDown
    permissions?: Permission[]
    chunk?: string               // 分包（Router M7.1）
    [key: string]: unknown
  }
}
```

> RouteIR 由 `<route>` 块 + 文件路径推导合并（Router M2）。

## BindingIR（对接 Pinia Vapor + Component）

```ts
interface BindingIR {
  type: 'Binding'
  kind: 'text' | 'attribute' | 'class' | 'style' | 'event'
  target: string                // 目标节点 id
  expr: string                  // 表达式（count.value）
  effect?: boolean              // 是否响应式（Vapor effect）
}
```

> Web codegen：`effect → el.textContent = ...`
> Skyline codegen：`effect → this.setData({ count })` 或节点操作

## ModuleIR（对接 Module 计划）

```ts
interface ModuleIR {
  type: 'Module'
  domain: string                // trade / user / content
  dependencies: { domain: string; version?: string }[]
  exports: string[]             // 对外暴露的 store/component/api
  chunk?: string                // 分包归属
  preload?: boolean             // 是否预加载
  capabilities?: string[]       // 依赖的平台能力
}
```

## 设计原则

### 1. 平台无关性（强制）

```ts
// ❌ 禁止：IR 里出现平台 API
{ type: 'Call', callee: 'wx.setStorageSync' }

// ✅ 正确：语义化节点
{ type: 'StorageSet', key: '...', value: '...' }
// → Web codegen: localStorage.setItem
// → Skyline codegen: wx.setStorage
```

> CI 审计（`proteus audit ir`）扫描 IR 里出现 `wx` / `document` 直接报错。

### 2. 确定性

IR 序列化结果必须稳定（排序、hash），保证：
- 增量编译缓存有效
- `--trace-transform` diff 有意义

### 3. 可序列化

IR 可 JSON 序列化 → 支持：
- 缓存到磁盘（`.proteus/cache/ir.json`）
- 跨进程传递（worker 并行编译）
- DevTools 可视化

## 与其他模块的关系

| IR 节点 | 消费方 |
|---------|--------|
| ComponentIR | Codegen 三端、Component 计划 |
| RouteIR | Router codegen（pages.json） |
| BindingIR | Pinia Vapor、Component 响应式 |
| ModuleIR | Module 依赖图 + 分包 |
| StoreIR | Pinia 持久化 |
| CapabilityIR | Platform codegen 分叉 |

## 验收

- [ ] 所有 IR 节点平台无关（CI 审计通过）
- [ ] SFC → IR → 三端产物 还原度 100%（快照测试）
- [ ] IR 可序列化 + 确定性
- [ ] 自定义 IR 节点可注册扩展
