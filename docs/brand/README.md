# Proteus 品牌资产（立方体）

**方向**：多彩立方体。图形**本体三面各持一色**（不是「纯色底 + 白字」）——
Fluent / Kotlin / Jetpack 一路的**多色几何**语言，比单色更有设计密度。

**隐喻**：等距立方体 = 一套源码；**三个面 = 多个渲染目标**；面间白色内缝 = 「同一体的多面」。

> **统一品牌标识**：立方体已同时用于 ① 小程序头像（本目录）② 官网导航 logo
> （`website/src/components/BrandMark.vue`）③ 网站图标 favicon（`website/public/favicon*.{svg,png}`）。
> 三处同源，改一处视觉请同步 —— 几何坐标见下方「几何」。

## 主选（`avatar`）

![主选](avatar-512.png)

白色圆角方形容器 + 三面渐变立方体（**紫 `#8b5cf6` / 绿 `#16a34a` / 蓝 `#2563eb`**）。
每面自带「上亮下暗」渐变 → 既有立体结构又是多色。内部三条棱描白（`7px` 圆头），
让三面边界清晰可辨；**外轮廓不描边**（靠面色收边，在任意底色上都干净）。

| 文件 | 用途 |
|---|---|
| `avatar.svg` | 源文件（可编辑，几何精确） |
| `avatar-512.png` | **512×512 成品（推荐上传件）** |
| `avatar-1024.png` | 1024×1024 高清 |
| `avatar-round.png` | 圆形裁切预览（非上传件） |

## 变体

| 文件 | 说明 |

## 衍生：Proteus Studio 的**两个标记**（决策 #1224 → #1228）

Studio 是**引擎的调试宿主**，不是第二个品牌。它有两个标记，**分工按尺寸**：

| | 应用图标 | 产品标记 |
|---|---|---|
| 文件 | `packages/studio/icons/icon.svg`（+ `-small` / `-preview`） | `docs/brand/studio-mark.svg`（+ `-glyph` 透明版） |
| 图形 | **P 字标**（极简） | **立方体 + 取景框** |
| 用在哪 | Dock / Finder / 菜单栏 / 关于面板 | 应用内空状态、文档、官网首屏 |
| 为什么 | 16–32px 只认剪影；字标的竖笔与碗在这个尺寸仍干净 | 取景框在 32px 会糊成四团脏点（实测 `icons/options/size-check.png`），所以只在**尺寸够大**的地方用 |

**两者的共同基因**：同一套等距角度（30°）、同一组三面三色（紫 `#8b5cf6` / 绿 `#16a34a` / 蓝 `#2563eb`）、
同一条"不描外轮廓、只描内缝"的规则。

### 应用图标：P 字标（紫/蓝 = 正式，绿/青 = 预览）

| 尺寸 | 文件 | 差异 |
|---|---|---|
| 16 / 32 px | `icon-small.svg` / `icon-preview-small.svg` | 字形放大 12%、**去投影、去高光扫带**、补光加强 |
| ≥ 64 px | `icon.svg` / `icon-preview.svg` | 完整版（回光 + 45° 高光扫带 + 柔和投影） |

**通道靠色相，不靠角标**（角标在 16px 就是噪点；VS Code Insiders / Chrome Canary 都是换色）：
正式 = 紫→蓝 + 绿补光；预览 = 绿→青 + 紫补光。
`package-app.sh --channel preview` 会装成 **Proteus Studio Preview**（bundle id 带 `.preview`），
两个通道可以同时装在一台机器上。

**生命感三件**（都是"光在动"的暗示，不是装饰）：回光（径向白 0.12）· 45° 高光扫带（0.09）·
预览版的扫描光带（横贯 + 4px 亮线）——最后一条用在立方体版上，语义是"正在取景"。

**图形规则**：竖笔 104（方角，不是胶囊）· 碗 r114 / 线宽 104 / 顶端与竖笔齐平 ·
外接 386×556 · 视觉居中 -32px（机械居中会让 P 偏右，因为碗的质量在右边）。

### 产品标记：立方体 + 取景框

取景框（四角 L）把立方体**框住** = 被检视、被取证——这正是 Studio 与引擎的分工：
引擎产出画面，Studio 把画面拿来比对与留证。

- `studio-mark.svg`：带深石墨底与紫光（文档/官网/OG 图用，方形成品）
- `studio-mark-glyph.svg`：**透明、无底**（应用内深色界面用；组件是 `ui/src/icons/StudioMark.vue`，
  渐变 id 前缀 `sm-`，避免和官网 BrandMark 的 `bm*` 撞）

**重新生成**（改完 SVG 必须跑，否则打包会带旧图标）：

```bash
node packages/studio/icons/make-icon.mjs   # 两个通道各出 icns + 1024 png
```

`pnpm run build:studio-app` / `:preview` 会在 **源 SVG 比 icns 新**时自动重跑；
门禁 `check:studio-panel` 的 ㉗ 会同时校验**两套** icns 的同步与分档尺寸。

## 小尺寸可读性

已降到 24 / 32 / 40 / 48 / 64 / 96 / 128px 实测：**@32 仍能清晰读出「三面立方体」**
（三色分面 + 白缝在极小尺寸下依然可辨）。小程序头像以小尺寸圆形展示（列表/详情约 40–96px），胜任。

## 几何（512 画布 · 精确值）

```
等距立方体 L=150，中心 (256,262)
顶面   256,112    385.9,187   256,262   126.1,187
左面   126.1,187  256,262     256,412   126.1,337
右面   256,262    385.9,187   385.9,337 256,412
内缝   UL(126.1,187)→C(256,262)、UR(385.9,187)→C、C→B(256,412)
容器   白色圆角方形 size=512 rx=116（≈22.7%，贴近 iOS squircle）
```

> ★制图注意：一页多图标时渐变 `id` 必须唯一（否则后定义的会覆盖前者，是 SVG 常见坑）。

## 重新生成

纯 SVG、无外部依赖：

```bash
qlmanage -t -s 512 -o . avatar.svg          # macOS 系统工具
# 或浏览器打开 avatar.svg 截图；或 sharp / resvg / rsvg-convert
```

**上传微信小程序头像**：登录 [微信公众平台](https://mp.weixin.qq.com) → 设置 → 基本设置 →
小程序头像（正方形、建议 512×512、PNG/JPG、<2MB、不透明）。**该设置在微信后台，不在代码仓库内**
（故主选容器用不透明白底；若要透明底请用 `avatar-transparent`，但微信通常要求不透明）。
