# TV 适配（智慧屏 / 机顶盒）

> 依赖：G-22.5（p-adaptive）/ G-25（三维断点 F=remote）
> 目标：**把 TV 的核心能力——焦点引擎——收敛为语义原语**

---

## 1. TV 的独特性：焦点引擎

TV 没有触摸，**所有交互靠遥控器 5 向导航**（上/下/左/右/确认）。
这不是"换个输入事件"，而是需要一个**焦点管理系统**：

- 当前焦点在哪个元素？
- 按"右"键焦点移到哪？
- 焦点离开容器时怎么办（环绕 / 停留在边缘）？
- 如何让用户"看见"焦点（焦点框 / 缩放 / 视差）？

**这是 uni-app / Flutter / RN 完全没有抽象的能力。** Proteus 把它做成语义原语。

---

## 2. 输入形态：F=remote

三维断点自动识别 TV：

```ts
useContainerProfile()
// → { w: 'xl', h: 'lg', f: 'remote' }  // 智慧屏
// → { w: 'xl', h: 'lg', f: 'remote' }  // 机顶盒
```

业务侧：

```vue
<p-grid :focusable="true" focus-mode="grid" :focus-wrap="true">
  <p-card v-for="item in items" />
</p-grid>
```

## 3. 焦点引擎原语

### 3.1 容器级：`<p-focus-scope>`

```vue
<p-focus-scope
  mode="grid"        ← grid | linear | manual
  :wrap="true"       ← 边缘环绕
  :remember="true"   ← 记住上次焦点
>
  <!-- 子元素自动获得焦点导航 -->
</p-focus-scope>
```

| `mode` | 含义 |
|--------|------|
| `grid` | 二维网格导航（上下左右） |
| `linear` | 一维列表（上下 / 左右） |
| `manual` | 手动指定 `:next-focus-up` 等 |

### 3.2 元素级：`focusable` + `focus-mode`

```vue
<p-card :focusable="true" focus-mode="grid" />
```

### 3.3 焦点事件

```vue
<p-button
  @focus="onFocus"
  @blur="onBlur"
  @select="onSelect"   ← 确认键
/>
```

## 4. 五端原生映射

| 端 | 焦点系统 |
|----|----------|
| **Android TV / 鸿蒙智慧屏** | `RecyclerView` + `FocusFinder` + **Leanback** 库 |
| **Apple TV** | `UIFocusSystem` + `UIFocusEnvironment` + **视差特效** |
| Web (SmartTV) | `:focus` + `tabindex` + `focus()` API |
| Skyline | 小程序 TV 扩展（焦点 API） |

**Compiler 把 `p-focus-scope` + `focus-mode` 编译为各端焦点声明**——开发者不写平台代码。

---

## 5. 远距大字（自动响应 xl 断点）

TV 观看距离 2-3 米，UI 必须大：

```vue
<p-text p-fluid="font-size(24, 36)" />   ← TV 自动取上限 36pt
<p-grid :min-col-width="280" />          ← 列数收敛，避免过密
```

`p-fluid` 在 `xl` 档位取 max 值，`p-grid` 列数自动减少。

---

## 6. 焦点视觉（G-07 Glass 协同）

焦点态需要强视觉反馈，复用 Glass 的边框/高光：

```vue
<p-card :focusable="true" focus-mode="grid">
  <template #focus-overlay>
    <pg-glass intensity="strong" border="focus" />   ← 焦点框
  </template>
</p-card>
```

Apple TV 的**视差特效**（按下时元素放大+倾斜）映射为 `transform: scale + perspective`。

---

## 7. 降级策略

| 场景 | 降级 |
|------|------|
| 非 TV 端使用 `p-focus-scope` | 退化为普通 `p-stack`（点击/触摸依然可用） |
| 无焦点系统（低端盒子） | 降级为 `tabindex` + 键盘模拟 |
| 无法检测 TV | 默认 `touch`，`p-focus-scope` 自动禁用 |

---

## 8. 严格规则

| 规则 | 级别 | 说明 |
|------|------|------|
| **TV001** | error | 可获焦组件必须声明 `focus-mode`（铁律 G-25.2） |
| TV002 | warning | TV 端文字不得小于 24pt |
| TV003 | error | TV 页面必须有且仅有一个初始焦点 |
| TV004 | warning | 避免焦点陷阱（用户无法退出焦点区） |

## 9. B3 落地要点

## 10. 小结

TV 适配的本质 = **焦点引擎语义化**。
这是竞品完全缺失的拼图，而 Proteus 用 G-25 的三维断点（F=remote）+ 原则 #10（系统原生映射）自然承接。

**`UIFocusSystem` / `FocusFinder` / Leanback → `p-focus-scope` + `focus-mode`**——
又一次"把终端厂系统能力搬进框架"。
