# G-40 规约增量变更

> 本文件描述 G-40 合并进 `proteus-architecture` 规约的内容。

---

## 1. 新增原则

### 原则 #13.11：执行载体可插拔

> **不得绑定任何一种执行载体。**
> JSI 是默认实现（JS 引擎路径），不是架构绑定。
> 业务代码必须能在 JSI / AOT / WASM 三条路径间切换而无需修改。

**理由**：不绑定 → JSI 的三条硬伤（跨界成本、字符串拷贝、线程亲和性）
从"架构死结"降级为"工程权衡"。

---

### 原则 #13.12：实时能力逃逸

> **实时能力必须在原生线程闭环运行，禁止由 JS 侧驱动循环。**

**理由**：`jsi::Runtime` 的线程亲和性是硬约束，
JS 驱动实时循环在架构上就是错误的，无法通过优化修复。

---

### 原则 #13.13：性能数据必须实测

> **对外宣称的任何性能数字，必须来自实测基准测试。**
> 工程推算必须标注 `measured: false`，且禁止对外引用。

**理由**：防止把推算当承诺。这是"证明先于宣称"（W-4）在性能领域的底线。

---

### 原则 #13.14：零拷贝降级必须显式

> **不支持零拷贝时必须返回 `null` 显式降级，
> 禁止静默返回拷贝对象。**

**理由**：静默拷贝比不支持更糟——它制造"性能谎言"，
让调用方以为零成本而实际仍在拷贝。

## 3. 全景图更新

### 修订前（L0–L4 五层）

```
L0 业务应用 (128 原语)
L1 框架内核 (IR/Diff/响应式/调度)
L2 能力后端 (G-28)
L3 渲染后端 (G-27)
L4 宿主运行时 (G-39)
     ↓
原生宿主
```

### 修订后（L0–L5 六层，新增执行载体层）

```
L0  业务应用 (128 原语)
         ↓ 只能调 Framework
L1  框架内核 (IR/Diff/响应式/调度)
         ↓ 调度
L2  能力后端 (G-28)          ← 实时类走逃逸协议
L3  渲染后端 (G-27)          ← commitBatch 批处理
L4  ★执行载体 (G-40)         ← 本次新增
         │  JSI / AOT / WASM
         ↓
L5  宿主运行时 (G-39)
         ↓
    原生宿主
```

### 为什么执行载体在宿主运行时之上

```
宿主运行时（G-39）= 提供进程、线程、事件循环、原生桥等"基础设施"
执行载体（G-40）  = 在基础设施之上，提供"代码执行环境"
```

**类比**：
- 宿主运行时 = 操作系统内核
- 执行载体 = 运行时（如 JVM / Node / .NET CLR）

一个宿主运行时可以承载多个执行载体（如 iOS 宿主可同时跑 JSI 和 AOT 模块）。

## 4. 对既有 Plan 的修正

### G-39 修正（必要）

```diff
  interface ProteusHostRuntime {
-   createEngine(config: EngineConfig): JSEngine
+   createEngine(config: CarrierConfig): ProteusExecutionCarrier
  }
```

**理由**：`JSEngine` 这个类型名**隐含"一定是 JS 引擎"**，
与 G-40 的载体抽象矛盾。改为 `ProteusExecutionCarrier` 后，
AOT / WASM 载体才能合法接入。

**兼容性**：这是前向兼容修正，已有 JS 引擎实现只需改返回类型声明。

---

### G-27 修正（增量）

```diff
  interface ProteusRenderBackend {
    updateNode(handle: NodeHandle, changes: IRDiff): void
+   /** G-40.5：批处理提交，必须实现 */
+   commitBatch(ops: RenderOp[]): void
  }
```

**兼容性**：向后兼容。未实现的 Backend 回退到循环调用单节点操作，但需告警。

---

  type ArtifactType =

    | 'wasm'

## 7. 风险边界

| 风险 | 影响 | 缓解 |
|------|------|------|
| AOT 路径开发成本高 | B5 周期长 | 按模块粒度渐进，核心先 AOT |
| 静态检查误报 | 业务代码被误拦 | 提供白名单机制 + 渐进开启（warn → error） |
| 批处理收益不及预期 | 性能优化无效 | B6 实测验证，不及预期则回退并重新设计 |
| 零拷贝在部分端不可用 | 降级影响性能 | 显式降级 + 指标上报，不静默 |
| 实时能力在 Web 端受限 | Web 无法完全对齐 | AudioWorklet 已是原生闭环，接受能力差异 |

---

## 8. 诚实边界（写入规约）

G-40 **不承诺**：

1. JSI 路径能解决线程亲和性（只能绕开，不能修复）
2. AOT 路径支持全部 JS 动态特性（需静态子集）
3. 批处理收益的具体倍数（需实测）
4. 零拷贝在所有端可用（依赖端能力）
5. 实时能力在 Tier 3/4 可用（无原生能力宿主）
