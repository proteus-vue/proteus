## 三句话概括

1. **官网不是"做个网站"**——它是开发者与框架之间唯一的契约界面，
   核心难题不是写出来，而是**在框架演进中不腐烂**。
2. **插件 API 文档必须是 renderer 不是 copy**——
   从 WIT 单一数据源生成，漂移即 CI 失败。
3. **更新私钥丢失不可逆**——是全套体系中唯一无法重来的风险。

## 关键决策速查

| 决策 | 选择 | 依据 |
|------|------|------|
| 文档站框架 | **Docusaurus** | 版本化为内置核心特性，不押社区插件（P3） |
| API 文档 | **自研 WIT renderer** | 无现成方案；WIT 非 OpenAPI |
| 未知版本 | **返回 null** | 静默降级会让用户按错版本写代码 |
| 未知平台产物 | **返回 null** | 错误的下载比没有下载更危险 |
| 漂移处理 | **阻断，不警告** | 警告会被忽略（G-59 论证） |
| 旧版本文档 | **保留 + noindex**，不删除 | 删除即制造 404（G-60.9） |
