# G-53 · 云真机适配

> ★ 独有增量。覆盖模拟器测不了的部分：**真机硬件 + 国产 ROM 深度定制**。

## 1. 什么时候才需要云真机

| 需求 | 模拟器能测？ | 必须云真机？ |
|------|------------|------------|
| 逻辑断言 | ✅ | ❌ |
| 渲染结果 | ✅ | ❌ |
| 真 JS 引擎行为 | ✅ | ❌ |
| **摄像头 / 蓝牙 / NFC** | ❌ | ✅ |
| **Face ID / 指纹** | ❌ | ✅ |
| **真实性能（帧率/内存/发热）** | ❌ | ✅ |
| **MIUI 杀后台 / 悬浮窗权限** | ❌（Android ROM） | ✅ |
| **厂商推送通道** | ❌ | ✅ |

**原则**：模拟器能覆盖的绝不花钱上云真机。**云真机只用于"模拟器的能力盲区"**。

## 3. 成本测算

以 8 台等价类代表机型 × 每次 5 分钟为例：

```
腾讯优测：8 × 5 × ¥0.5 = ¥20/次
每天跑一次回归 = ¥600/月
```

对比买 8 台真机（3-5 万 + 折旧 + 维护）：**云真机成本约 1/50**。

**更低的方案**：云手机（星界 / BitCloudPhone）约 30 元/月/台，折算 **0.08 元/小时**——开 100 台跑 3 小时才 39 元。适合**大规模并发冒烟**，但不适合需要精确硬件行为的场景。

## 4. SPI 适配

```typescript
interface CloudDeviceProvider {
  name: string
  listDevices(): Promise<MobileDeviceProfile[]>
  reserve(profile: MobileDeviceProfile): Promise<DeviceHandle>
  release(handle: DeviceHandle): Promise<void>
  quota(): Promise<{ remaining: number; unit: 'minute'|'credit' }>
}
```

**额度耗尽的处理**（★ 关键）：

```
quota() → remaining = 0
    ↓
抛 QUOTA_EXCEEDED
    ↓
编排器捕获 → 降级到下一档 或 返回 SKIP
    ↓
★ CI 不阻断，报告标注"覆盖率下降"
```

**严禁**：额度耗尽直接 FAIL——这会让 CI 因外部计费问题随机红，是典型的反模式（AP-27）。

## 5. 自动化框架选型

| 框架 | Flakiness | 上手 | 建议 |
|------|-----------|------|------|
| **Maestro** | **<1%** | 5 分钟 | **推荐** |
| Appium | 10-15% | 1-2 天 | 生态大，但 Flakiness 硬伤 |
| Airtest | 中 | 低 | 图像识别，适合游戏/非标 UI |

**推荐 Maestro 的理由**：

- **YAML 声明式**，与 G-52 的 `TestSuite` IR 天然同构——可直接从 IR 生成
- 零驱动配置，CLI 二进制，CI 友好
- **内置重试 + 智能同步**，Flakiness <1%——**这对 CI 稳定性是决定性的**（Appium 10-15% 的 Flakiness 会让团队逐渐不信任 CI，最终弃用）

**限制**：iOS 真机需 Maestro Cloud 付费，本地仅支持模拟器。但结合"绝大部分断言不需真机"，影响很小。

## 6. 云真机的能力盲区（诚实清单）

即便云真机也不是万能：

| 项目 | 云端表现 |
|------|---------|
| NFC 刷卡 | 多数平台不支持或需定制 |
| 蓝牙配对 | 支持有限 |
| 相机模组差异 | 云端设备固定，无法覆盖全部模组 |
| 指纹/面容 | 通常不可用 |
| 真实网络切换（4G/5G/WiFi 切换） | 部分平台支持 |
| 陀螺仪/气压计 | 多数不支持 |

**因此**：云真机用于**常规功能与兼容性回归**，硬件深水区仍需少量真机 + 人工探索性测试。

## 7. 与模拟器池的分工

```
                ┌─ ios-sim-remote（共享 Mac 池）  → iOS 逻辑/渲染/引擎，零边际成本
设备供给 ───────┤
                └─ cloud-device（云真机）          → 国产 ROM + 真硬件，¥0.5/分钟
```

**决策规则**（编排器自动执行）：
- suite 需要 `hardware` 或 `realRom` → 云真机
- 否则 → 模拟器池（免费）
- 云真机额度耗尽 → 降级到模拟器池 + 标注 DEGRADED
