# G-53 Conformance

## 不变量

| ID | 命题 | 验证 |
|----|------|------|
| **INV-M1** | 平台不可用 → `SKIP`，不抛异常、不 FAIL | `boot()` 在 `available=false` 时返回 SKIP |
| **INV-M2** | 能力缺失 → `DEGRADED` + missing 列表，不静默通过 | `runIsolated()` 检测需求 vs 档位能力 |
| **INV-M3** | 编排器按能力自动选档，无需人工指定 | `selectTier()` |
| **INV-M4** | 覆盖率加权份额取上限 1，不虚报 >100% | `weightedShare()` |
| **INV-M5** | 空等价类 / 零执行 → 阻断（pass=false） | `CoverageGate.evaluate()` |
| **INV-M6** | SKIP 拉低 execRate，不计入 PASS | execRate 计算 |
| **INV-M7** | 云真机额度耗尽 → 降级/SKIP，不阻断 CI | `QUOTA_EXCEEDED` 处理 |
| **INV-M8** | 报告携带 skipped 列表，覆盖率不黑盒 | 报告结构 |

## 负向自检（NEG-01 ~ NEG-04）

| ID | 命题 | 为什么要测 |
|----|------|-----------|
| NEG-01 | 门槛 1.0 且份额 <1 → 阻断 | 防"虚报满覆盖" |
| NEG-02 | 空等价类 → share=0 且阻断 | 防"没测任何东西 = 通过" |
| NEG-03 | 多项能力缺失**全部**记录，不合并 | 防"只报第一个缺失"掩盖问题 |
| NEG-04 | 编排器接受单后端，不要求满配 | 防"没配齐就崩" |

## 与既有体系的接缝

| 命题 | 组合 |
|------|------|
| **G-51 ∧ G-53** | `NativeAdapter.runIsolated()` 契约在设备供给维度上扩展，语义不变 |
| **G-52 ∧ G-53** | `DeviceProfile` 扩展 vendor/share/supply，等价类理论一致 |
| **G-46 ∧ G-53** | RSC-01「缺失即降级，永不崩溃」贯穿到验证基础设施本身 |
| **G-51 INV-06 ∧ G-53 INV-M8** | 报告可序列化 + skipped 列表 → CI 可消费且透明 |
