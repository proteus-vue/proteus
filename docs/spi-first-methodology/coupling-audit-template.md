## 第一步：扫描（Coupling Audit）

对每个疑似耦合点执行：

```bash
# 通用扫描
grep -rc "<具体实现名>" . | sort -t: -k2 -rn | head -20

# JS/TS 项目
grep -c "from '<sdk-name>'" **/*.ts

# Java/Kotlin
grep -c "import com.<vendor>" **/*.java

# Python
grep -c "import <module>" **/*.py
```

**优先级判定**：
- **P0**：出现 ≥ 20 文件 **且** 未来确定要替换 / 多实现并存 / 第三方扩展
- **P1**：出现 5-19 文件，或有明确的演进计划
- **P2**：出现 < 5 文件，记录但暂不处理
