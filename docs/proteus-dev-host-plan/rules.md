# G-45-E4：铁律 + 严格规则

---

## 1. 铁律 G-45.1-6

| 编号 | 铁律 | 理由 |
|------|------|------|
| **G-45.1** | **基座零插件知识：基座代码禁止静态依赖/感知任何具体插件（只依赖 ProteusDevHost SPI + 装载协议）；新插件接入禁止修改基座一行代码** | 基座是宿主不是载体——这是「永不重打」的架构前提 |
| **G-45.2** | **未装载能力的语义调用必须走转发桩 pending 语义（装载后回放），禁止抛同步异常、禁止要求业务写重试** | 对齐 G-32.3 非抛语义；业务循环与原生循环解耦的核心 |
| **G-45.3** | **装载即验证：动态模块必须过签名校验 + conformance 快检（每能力 ≥1 用例），任一 FAIL 拒绝装载并降级，禁止带伤注册** | 动态性不能以正确性为代价——conformance 方法论第八套套件 |
| **G-45.4** | **双层产物强制分离：基座 cacheKey = f(框架版本, ABI)，禁止含页面数/插件数等业务规模因子；基座构建频次必须为「每框架版本 1 次」** | 「页面越多打包越慢」的根因消除，机器可检（C-07 + CMP086） |
| **G-45.5** | **动态装载全链可观测：loaded/upgraded/rejected/fallback/pending/replay 必须发事件（TraceBus 同源），禁止静默降级** | 对齐 G-37.6 / G-39.4 降级可观测纪律 |
| **G-45.6** | **发布形态诚实边界：商店发布包必须回静态链接（每版本一次）；动态装载通道禁止用于规避商店审核或绕过分发合规** | iOS 2.5.2 / Play 动态代码政策；合规是铁律不是建议 |

## 2. CMP082-088（编译期/CI 门禁）

| 规则 | 级别 | 说明 | 载体 |
|------|------|------|------|
| CMP082 | error | 基座工程禁止 import/引用任何插件模块（构建期依赖扫描，G-42.6 fork 扫描同源） | `proteus audit host` |
| CMP083 | error | 业务代码对未声明已装载能力的调用必须经转发桩（pending 语义），发现裸 await 原生桥直调即报错 | compiler 插件 |
| CMP084 | error | 插件 bundle 必须携带完整 manifest + 有效签名，缺一拒绝装载 | DevHost 门禁 |
| CMP085 | error | 装载必须执行 conformance 快检，FAIL 拒绝 + fallback 事件（报告含逐用例结果） | DevHost 门禁 |
| CMP086 | error | 构建计划检查：base cacheKey 不得含规模因子；插件 cacheKey 必须按 (id, version) 独立 | `proteus build --plan` |
| CMP087 | error | 插件 conformance 覆盖率：用例数 ≥ 能力数；每能力至少一条 shape 契约 | 插件 CI + 装载门禁 |
| CMP088 | error | 调试推送通道必须 TLS + token + bundle 签名，全量审计日志（防通道滥用注入） | dev server |
