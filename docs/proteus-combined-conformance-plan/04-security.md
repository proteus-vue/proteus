# G-47 安全与正确性：组合层铁律

## 1. 组合层专属铁律（CCI 系列）

继承自 G-46 RSC 系列 + G-27 RND 系列，**新增组合层约束**：

| 编号 | 铁律 | 对应不变量 |
|------|------|-----------|
| **CCI-01** | Backend 不得缓存 `readAuth` 结果；每次查池 | INV-01/05 |
| **CCI-02** | `unmount()` 不得销毁池内任何资源 | NEG-02 / INV-03 |
| **CCI-03** | 切后端必须以**原子事务**提交（mount 新 + unmount 旧 不可分割） | INV-04 |
| **CCI-04** | 登出与切后端**串行化**（同一锁） | INV-03 |
| **CCI-05** | 不可用后端必须**显式抛错**（禁止静默吞错） | INV-06 |
| **CCI-06** | 组合 conformance 必须 100% PASS，0 warning | 全部 |

## 2. 攻击树（组合层特有风险）

```
目标：窃取/污染跨后端共享登录态
├── A. 后端缓存投毒
│   └── 后端缓存旧 sid → 登出后仍用旧值 → 僵尸会话
│       防御：CCI-01（每次查池）+ CCI-04（登出串行化）
├── B. unmount 资源回收
│   └── 后端 unmount 清掉共享 Cookie → 他后端突然登出
│       防御：CCI-02（unmount 不触池）+ NEG-02 断言
├── C. 竞态：切后端 ∩ 登出
│   └── 读到半登出态（cookies 空但 tokens 未清）
│       防御：CCI-03/04（原子 + 串行）+ INV-03 交换律测试
└── D. 降级链污染
    └── 回退后端读到首选后端的私有残留
        防御：池是唯一真理源（P1）+ INV-06
```

## 3. 竞态安全论证（INV-04）

参考实现 `INT-D`（600 次并发 mount + read + logout）验证"**不崩溃**"。
**真实平台的强论证需 B3 阶段**（Android 主线程 / iOS GCD / 鸿蒙 TaskDispatcher）：

- **写锁**：`ResourcePool` 所有写操作（setCookie/setToken/logout）持同一锁
- **读快照**：`readAuth` 读时取当前快照，容忍 stale-but-safe（不超过 1 帧）
- **登出屏障**：logout 是**全池写屏障**，之后的 read 必见空

**诚实边界**：当前 node 单线程模拟**未真实验证多线程竞态**——`INT-D` 仅证明"接口不崩溃"，**强一致性待 B3 原生侧用线程消毒剂（TSan/ASan）验证**。

## 4. 负向测试判别力（G-44 方法论要求）

G-47 的每个负向用例必须满足：**把断言写反 → 测试 FAIL**。已验证：

| 用例 | 若实现错误 |
|------|-----------|
| NEG-02（unmount 后池存活） | 若 Backend 私有持有登录态 → 此处 FAIL ✅ |
| NEG-03（重挂载读到同一态） | 若池被清 → 此处 FAIL ✅ |

**判别力审查**：`reference-impl.cjs` 的 NEG-02 专门设计为"对错误设计敏感"——这是 CCI-02 的机器化表达。

## 5. 反模式（AP-Combo 系列）

| 反模式 | 症状 | 检测 |
|--------|------|------|
| **AP-C1 后端私有会话** | Backend 自存 sid/token | NEG-02 FAIL |
| **AP-C2 切后端无事务** | 切换瞬间读到空态 | INV-03 交换律 FAIL |
| **AP-C3 静默吞装载错误** | 不可用后端默默退化 | CCI-05 违规 |
| **AP-C4 单层测试自足** | 以为 G-27+G-46 PASS 即组合正确 | G-47 整体缺失 |

## 6. 与 G-44 / G-45 的衔接

- **G-44（Test IR）**：G-47 的六不变量表达为 `Test IR` 的 `AssertionNode`，可在 Node/JSI/AOT/Host/Device 多后端跑
- **G-44（INT 系列）**：G-47 即 INT-06~INT-0N，纳入统一 conformance runner
- **G-45（装载验证）**：Backend 装载时同步跑 G-47 快检（§3.6）
