# G-47 铁律（Rules）

## 1. 组合层铁律（CCI 系列）

| 编号 | 级别 | 铁律 |
|------|------|------|
| **CCI-01** | error | Backend 不得缓存 `readAuth` 结果；每次查共享池 |
| **CCI-02** | error | `unmount()` 不得销毁池内任何资源 |
| **CCI-03** | error | 切后端须原子事务（mount 新 + unmount 旧 不可分割） |
| **CCI-04** | error | 登出与切后端须串行化（同一锁） |
| **CCI-05** | error | 不可用后端必须显式抛错（禁止静默吞错） |
| **CCI-06** | error | 组合 conformance 必须 100% PASS，0 warning |

## 4. 与原则 #0 的关系

G-47 是「不绑定测试层级」的方法论应用：

```
G-44 不绑定测试实现（Test IR + Backend）
G-47 不绑定"测试层级" ← ★ 本份
      ↑
      单层测试 → 组合测试，同一套 Test IR / runner
```

**原则 #0 投影链**（截至 G-47）：

```
平台API → 渲染 → 编译 → 宿主 → 载体 → 容器 → 所有权
        → 测试(G-44) → 基座(G-45) → 资源容器(G-46) → ★验证层级(G-47)
```

## 6. 编号避让登记

本包按库内纪律登记以下编号动作，供全局规约合并时核对：

- **CMP 平移**：本包全局 CMP 由原稿 103-108 平移为 **CMP097-102**（103→097、104→098、…、108→102；官方 G 表止于 CMP088，G-46=CMP089-096，G-47=CMP097-102）。
- **G-41 重指向**：本包正文旧号 G-41（测试框架/Test IR/统一 runner）一律改指 **G-44**；G-41 现仅指 host-integration（宿主接入）。
- **INT 局部套件命名并存**：INT-A~E 是本包**局部套件标签**（INT-A1~E2 组合层扩展命名），与 G-44 全局的 INT-01~05 并存但语义不同——避免将 INT-A7 误读为全局 INT 系列续号（G-47 用例在 G-44 Test IR 中登记时另行分配全局位）。
- **G-45 依赖补登**：G-47 依赖含 G-45（装载即验证），README / MANIFEST / architecture-update 三处清单一致。
