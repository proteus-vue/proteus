# G-47 架构规约增量

## 1. 原则增量

新增原则：

> **原则 #13.34（组合正确性）**：跨层组合的正确性必须由独立 conformance 套件证明，不得由各自单层的 PASS 推导。

> **原则 #13.35（资源归宿主）**：登录态/Cookie/Token 属于共享 ResourcePool，不属于任何 RenderBackend；Backend unmount 不得销毁资源。

> **原则 #13.36（切换原子性）**：渲染后端切换是原子事务，且与登出操作串行化。

## 2. 测试金字塔（更新）

```
              /\
             /E2E\       业务场景
            /──────\
           / 接缝   \  ← ★ G-47 组合一致性（新增层）
          / COMBO    \
         /────────────\
        /  INTEG/SPI   \  G-46 池 / G-27 后端
       /────────────────\
      /    UNIT           \ 属性测试
     /────────────────────\
```

**接缝测试（seam test）**是新增概念：专门覆盖模块接口交界处，这是单元测试够不到、E2E 太昂贵的最佳性价比层。
