# G-48 铁律

## G-48 架构纪律（8 条）

| 编号 | 铁律 | 出处 |
|------|------|------|
| **G-48.1** | **不绑定运行时形态**：运行时只定义标准接口，平台差异全部封装在 Platform Adapter | 原则 #0 |
| **G-48.2** | **不绑定小程序平台**：业务逻辑零平台分支，跨 Adapter 结果 shape 一致 | PRIM001 |
| **G-48.3** | **双线程语义不可绕过**：逻辑层不得直连视图层，唯一通道 = setData | 04 §2.1 |
| **G-48.4** | **setData 数据必须可序列化**：禁函数 / 循环引用 / undefined | RT-02/03 |
| **G-48.5** | **凭证最小化**：小程序只拿 scopedToken，不拿原始登录态（RSC-01） | CMP-103 |
| **G-48.6** | **AppID 隔离**：存储 / 凭证按 AppID 分桶，跨桶拒绝；MVP = L1 逻辑隔离，开放平台需 G-49 | CMP-104 |
| **G-48.7** | **降级不崩溃**：L2 部分支持 → 降级 + 警告；L3 不支持 → 明确 reject（不静默） | 原则 #4 |
| **G-48.8** | **装载即验证**：Adapter 装载跑 conformance，不过门禁 → 拒绝 + 降级兜底 | G-45 |

## 反模式（AP-Adapter）

| 编号 | 反模式 | 后果 |
|------|--------|------|
| AP-01 | Adapter 内含业务逻辑 | 无法复用 |
| AP-02 | L3 能力静默返回 mock | 业务以为成功，实则失败 |
| AP-03 | 直接返回原始登录态 | 凭证泄漏（违反 RSC-01） |
| AP-04 | 能力级别声明与实际不符 | 兼容矩阵不可信 |
| AP-05 | 绕过 setData 直连视图层 | 破坏双线程隔离 |
| AP-06 | 一个 Adapter 覆盖多平台 | 退化为条件分支（PRIM001） |
