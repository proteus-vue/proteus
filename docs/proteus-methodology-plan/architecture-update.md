## 新增原则

### 原则 #0（最高层，统摄全部）：统一语义收敛（Unified Semantic Convergence）

> **定义与平台无关的语义内核；一切平台差异下沉为后端实现细节。**
> 任何跨端问题 = 语义定义（框架做）+ 后端实现（平台做）。

此原则是 G-27 / G-28 / G-29 / G-30 的**共同上位原则**，也是整套架构的唯一根基。
其余所有原则（#1-#10）均为本原则的展开。

## 风险边界

- 方法论统一 ≠ 强制一刀切：各 Backend 可声明自身 capabilities，缺失即编译期报错（支柱 ③）
- 不承诺：纯后端 / 无 JS 无渲染的裸 MCU / 强实时强安全隔离 / 封闭生态不允许嵌入 JS
