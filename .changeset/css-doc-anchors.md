文档引擎：标题显式锚点 `{#id}` + 悬停 `#` 深链图标

- **显式锚点**：`### 标题 {#custom-id}`（MDN / VitePress 同款）——给定稳定 id，供深链/外部引用；未给定时仍按标题文本自动 slug 化（行为不变）。标题文本会剥离 `{#id}` 后缀，不进正文与目录。
- **悬停锚点链接**：每个标题渲染一个 `#` 深链图标（`docs-anchor`），鼠标悬停标题时显形，一键复制/跳转本节；键盘 `:focus-visible` 可达。
- 动机：官网 CSS 多端支持参考页从「单张 79 行大表格」重做为「按类别分节 + 每能力独立小节 + 顶部能力索引」，**逐能力可跳转锚点**（对标 MDN / Can I Use 的属性参考形态）；锚点契约 = SSOT 行的 `id`（稳定、不受标题文本变化影响），配套门禁见 `tests/css-capability-alignment.test.ts` ⑥。
