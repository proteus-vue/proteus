# useLogin

**What it does**: Get a platform login code to exchange for your own session.

**When to use it**: WeChat login, silent login.

> 技术标识：能力原语 C41 · `capability.login` · 返回 `Result<Token>` · **Hook implemented** (per-end support in the table below)

useLogin: login (wx.login → code / integrate a third-party provider)

## Signature

```ts
useLogin(provider?: string): Promise<CapResult<LoginResult>>
```

## Parameters

Param,Type,Required,Doc
|---|---|---|---|
| `provider` | `string` | No | Service provider identifier (wechat / web / host-defined) |

## Returns

`Promise<CapResult<T>>` — iron rule: no callbacks, no try/catch duty; branch on `res.ok`:

| Property | Type | Doc |
|---|---|---|
| `ok` | `boolean` | Succeeded `true` / failed `false` |
| `data` | `LoginResult` | Success payload (structure below) |
| `error` | `CapError` | Present on failure: `code` (machine code) / `message` (human-readable reason) / `cause` (original exception) |

## Props

| Prop | Type | Required | Doc |
|---|---|---|---|
| `provider` | `string` | Yes | Login channel (wechat / host-provider …) |
| `code` | `string` | No | Login credential (wx code; the server exchanges it for a session) |
| `token` | `string` | No | Token (when a third-party provider issues the token directly) |

## Error codes

| code | Doc |
|---|---|
| `login.unsupported` | The bridge does not provide login (useLogin unavailable) |
| `login.failed` | wx.login failed |

> Platform unsupported → the `*.unsupported` family; business branches on `code`, no try/catch needed.

## Usage

```ts
const res = await useLogin('wechat')

if (res.ok) {
  console.log('provider:', res.data.provider, res.data.code ?? res.data.token ?? '')
} else if (res.error.code.endsWith('.unsupported')) {
  // platform unsupported → degradation path
}
```
