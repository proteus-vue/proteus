# useNotification

useNotification: Message subscription authorization (wx.requestSubscribeMessage / web Notification)

> Capability primitive C17 · `capability.notification` · returns `NotificationAPI` · **Hook implemented** (API ready — target bridges in the table below)

## Signature


## Parameters

| Parameter | Type | Required | Doc |
|---|---|---|---|
| `templateId` | `string` | Yes | Subscription message template ID (registered on the Official Platform) |

## Returns

`Promise<CapResult<T>>` — iron rule: no callbacks, no try/catch duty; branch on `res.ok`:

| Property | Type | Doc |
|---|---|---|
| `ok` | `boolean` | Succeeded `true` / failed `false` |
| `data` | `MessageSubscription` | Success payload (structure below) |
| `error` | `CapError` | Present on failure: `code` (machine code) / `message` (human-readable reason) / `cause` (original exception) |

#### Properties of the `data` (`MessageSubscription`) object

| Property | Type | Required | Doc |
|---|---|---|---|
| `templateId` | `string` | Yes | Template ID (for wx, must first be applied for on the Official Platform) |
| `granted` | `boolean` | Yes | Whether authorization was granted (wx: the status of this template in tmplIds; web: Notification.requestPermission granted) |
| `status` | `string` | No | Raw status text (wx: 'accept'/'reject'/'ban'; web: 'granted'/'denied'/'default') |
