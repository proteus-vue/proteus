# useQRCode

**What it does**: Scan QR/barcodes, or generate QR codes.

**When to use it**: Scan-to-login, scan-to-pay, share codes.

> 技术标识：能力原语 C42 · `capability.qr-code` · 返回 `Result<string>` · **Hook implemented** (per-end support in the table below)

useQRCode: scan a QR code (wx.scanCode; web needs a camera capture source → Err fallback)

## Signature

```ts
useQRCode(): Promise<CapResult<string>>
```

## Returns

`Promise<CapResult<T>>` — iron rule: no callbacks, no try/catch duty; branch on `res.ok`:

| Property | Type | Doc |
|---|---|---|
| `ok` | `boolean` | Succeeded `true` / failed `false` |
| `data` | `string` | Success payload |
| `error` | `CapError` | Present on failure: `code` (machine code) / `message` (human-readable reason) / `cause` (original exception) |

## Error codes

| code | Doc |
|---|---|
| `qr-code.unsupported` | The bridge does not provide scanQR (useQRCode unavailable) |
| `qr-code.failed` | wx.scanCode failed |

> Platform unsupported → the `*.unsupported` family; business branches on `code`, no try/catch needed.
