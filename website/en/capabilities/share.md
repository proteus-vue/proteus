# useShare

**What it does**: Share content to chat apps and social feeds.

**When to use it**: Invites, sharing products.

> 技术标识：能力原语 C18 · `capability.share` · 返回 `Result<void>` · **Hook implemented** (per-end support in the table below)

Sharing (wx.shareAppMessage / navigator.share / mock)

## Signature

```ts
useShare(options: ShareOptions): Promise<CapResult<void>>
```

## Parameters

Param,Type,Required,Doc
|---|---|---|---|
| `options` | `ShareOptions` | Yes | Options object (fields in the table below) |

#### Properties of `options`

| Property | Type | Required | Doc |
|---|---|---|---|
| `title` | `string` | No | Share title |
| `text` | `string` | No | Share text (used by web navigator.share; omitted on Mini Program) |
| `url` | `string` | No | Share link (must be an HTTPS URL on web) |

## Returns

`Promise<CapResult<T>>` — iron rule: no callbacks, no try/catch duty; branch on `res.ok`:

| Property | Type | Doc |
|---|---|---|
| `ok` | `boolean` | Succeeded `true` / failed `false` |
| `data` | `void` | No payload on success |
| `error` | `CapError` | Present on failure: `code` (machine code) / `message` (human-readable reason) / `cause` (original exception) |

## Error codes

| code | Doc |
|---|---|
| `share.unsupported` | navigator.share is not supported (requires HTTPS + a user gesture) |

> Platform unsupported → the `*.unsupported` family; business branches on `code`, no try/catch needed.
