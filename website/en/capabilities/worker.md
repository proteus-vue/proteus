## Platform notes

### Mini Program (MP)

- **wx.createWorker (real thread)** — Mini Program multithread Worker: an isolated JS context communicating via postMessage — declare the worker dir in app.json

### Web

- **Web Worker (real thread)** — new Worker(url) runs on a separate thread; onMessage can be unsubscribed via removeEventListener (more complete than MP)
- **Cross-thread data limits** — Structured clone (no reference sharing); use Transferables for large payloads (ArrayBuffer ownership transfer, zero copy)

### App (iOS / Android / Harmony)

- **Shell background threads (G-39 runOnThread)** — App-side "threads" come from the host runtime (G-39 single ownership) — the bridge creates them via the shell; business code never spawns threads directly · Planned: Available once the shell implements `worker.create/post/terminate`
