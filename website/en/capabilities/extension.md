# useExtension

useExtension: extension/plugin (G-21 extension point — host loadPlugin bridge; Err by default)

> Capability primitive C50 · `capability.extension` · returns `ExtensionAPI` · **Hook implemented** (API ready — target bridges in the table below)

## Signature

```ts
useExtension(extensionId: string): Promise<CapResult<unknown>>
```

## Parameters

Param,Type,Required,Doc
|---|---|---|---|
| `extensionId` | `string` | Yes | Extension/plugin ID (registered name of the G-21 extension point) |

## Returns

`Promise<CapResult<T>>` — iron rule: no callbacks, no try/catch duty; branch on `res.ok`:

| Property | Type | Doc |
|---|---|---|
| `ok` | `boolean` | Succeeded `true` / failed `false` |
| `data` | `unknown` | Success payload |
| `error` | `CapError` | Present on failure: `code` (machine code) / `message` (human-readable reason) / `cause` (original exception) |

## Error codes

| code | Doc |
|---|---|
| `extension.unsupported` | The bridge does not provide loadExtension (useExtension unavailable) |

> Platform unsupported → the `*.unsupported` family; business branches on `code`, no try/catch needed.

## Usage

```ts
const res = await useExtension('com.acme.exporter')

if (res.ok) {
  console.log('extension returned:', res.data)
} else if (res.error.code.endsWith('.unsupported')) {
  // platform unsupported → degradation path
}
```

## Platform notes

### Mini Program (MP)

- **No plugin-loading API** — Mini Programs cannot load external code at runtime — a host extension shell (same-layer rendering / dynamic components) is required, see docs/proteus-platform-plan

### Web

- **Dynamic import()** — Loads ES modules at runtime (a real implementation); accepts module URLs only (relative/absolute/http(s)) — bare specifiers are rejected

### App (iOS / Android / Harmony)

- **Shell-loaded native modules (same mechanism as G-45)** — Apps can dynamically load native modules (Android DexClassLoader / iOS dynamic libraries) — the same mechanism as dev-host plugin loading · Planned: Available once the shell implements `extension.load`
