# useSocket

**What it does**: Send and receive raw bytes over UDP or TCP.

**When to use it**: IoT device protocols, custom protocols.

> 技术标识：能力原语 C69 · `capability.socket` · 返回 `UDPSocketHandle / TCPSocketHandle` · **Hook implemented** (per-end support in the table below)

useSocket: low-level sockets — UDP (bind/connect/send/write/onMessage) and TCP (connect/write/onMessage/close) (wx.createUDPSocket/createTCPSocket; web browsers do not expose raw UDP/TCP → Err, use WebSocket/WebRTC)

## Signature

```ts
useSocket(): CapResult<{ udp(): UDPSocketHandle; tcp(options?: TCPSocketConnectOptions): TCPSocketHandle }>
```

## Returns

`Promise<CapResult<T>>` — iron rule: no callbacks, no try/catch duty; branch on `res.ok`:

| Property | Type | Doc |
|---|---|---|
| `ok` | `boolean` | Succeeded `true` / failed `false` |
| `data` | `{ udp(): UDPSocketHandle; tcp(options?: TCPSocketConnectOptions): TCPSocketHandle }` | Success payload |
| `error` | `CapError` | Present on failure: `code` (machine code) / `message` (human-readable reason) / `cause` (original exception) |

## Error codes

| code | Doc |
|---|---|
| `socket.unsupported` | The socket API is missing (browsers do not expose raw UDP/TCP — use WebSocket/WebRTC or a host bridge) |

> Platform unsupported → the `*.unsupported` family; business branches on `code`, no try/catch needed.

## Usage

```ts
const sock = useSocket() // synchronous handle — no await, no res.ok

if (sock.ok) {
  const udp = sock.data.udp()
  await udp.bind(8080)
  udp.onMessage((m) => console.log('received:', m.remoteAddress, m.remotePort))
  await udp.send('192.168.1.1', 9000, 'ping')
  // or TCP: const tcp = sock.data.tcp(); await tcp.connect({ address, port })
} else if (sock.error.code === 'socket.unsupported') {
  // browsers cannot open raw sockets → degradation path (WebSocket/WebRTC)
}
```
