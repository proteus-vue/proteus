# useKeyboard

**What it does**: Get the software keyboard height and visibility.

**When to use it**: Keeping inputs visible, pushing chat bars up.

> 技术标识：能力原语 C14 · `capability.keyboard` · 返回 `KeyboardInfo` · **Hook implemented** (per-end support in the table below)

## Usage

```ts
const kb = useKeyboard() // synchronous handle — no await, no res.ok

console.log('keyboard height:', kb.info.height, 'visible:', kb.info.visible)
const off = kb.onChange((info) => console.log('keyboard height changed:', info.height, info.visible))
// off() unsubscribes
```
