## Usage

```ts
const kb = useKeyboard() // synchronous handle — no await, no res.ok

console.log('keyboard height:', kb.info.height, 'visible:', kb.info.visible)
const off = kb.onChange((info) => console.log('keyboard height changed:', info.height, info.visible))
// off() unsubscribes
```
