# useAuth

useAuth: authentication state composition (token custody + login/logout + subscription) — business code never reads the raw token (iron rule 2)

> Capability primitive C33 · `capability.auth` · returns `AuthState` · **Hook implemented** (API ready — target bridges in the table below)

## Signature

```ts
useAuth(): AuthState
```

## Returns

Returns `AuthState` (synchronous handle/state object).

#### Properties of `AuthState`

| Property | Type | Doc |
|---|---|---|
| `token` | `string \| null` | Current token (null when not logged in; reactive — bind directly in the UI) |
| `isAuthenticated` | `boolean` | Whether the user is logged in (true when the token is non-empty) |
