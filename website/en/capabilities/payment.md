# usePayment

**What it does**: Start a payment and receive the result.

**When to use it**: Checkout, top-ups.

> 技术标识：能力原语 C40 · `capability.payment` · 返回 `Result<PayResult>` · **Hook implemented** (per-end support in the table below)

usePayment: Launch payment (wx.requestPayment fields)

## Signature

```ts
usePayment(config: PaymentConfig): Promise<CapResult<PaymentReceipt>>
```

## Parameters

Param,Type,Required,Doc
|---|---|---|---|
| `config` | `PaymentConfig` | Yes | C40 payment parameters (aligned with wx.requestPayment core fields — issued by the server after the order is placed) |

#### Properties of `config`

| Property | Type | Required | Doc |
|---|---|---|---|
| `timeStamp` | `string` | Yes | Timestamp (seconds-level string, generated by the server) |
| `nonceStr` | `string` | Yes | Random string (server-generated, within 32 characters) |
| `package` | `string` | Yes | prepay_id returned by the unified order API (format paySign=...) |
| `signType` | `string` | No | Signature method (defaults to MD5/platform default when omitted; RSA recommended) |
| `paySign` | `string` | Yes | Signature (computed by the server with the merchant private key) |

## Error codes

| code | Doc |
|---|---|

## Usage

```ts
const res = await usePayment({ timeStamp: '1725600000', nonceStr: 'a1b2c3d4', package: 'prepay_id=wx2501010001', paySign: 'SIGN' })

if (res.ok) {
  console.log('payment:', res.data.provider, res.data.transactionId ?? '')
} else if (res.error.code.endsWith('.unsupported')) {
  // platform unsupported → degradation path
}
```
