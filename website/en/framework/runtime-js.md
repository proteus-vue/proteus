# JavaScript support & runtime environment

The Mini Program logic layer is an **independent JS runtime**: no DOM/BOM, and a module system unlike the browser's. For business code to run on both targets, you need to know where the boundary is.

## Artifact baseline: ES5-safe

All JS artifacts generated by the compiler avoid `??` / `?.` / array destructuring / object spread (explicit null-check ternaries, indexed `Object.keys` loops, direct property assignment).

> Why: when WeChat DevTools converts page JS to ES5 it relies on babel helper modules; if the helpers are not in the bundle it errors, and real-device preview throws a syntax error outright (evidenced by decisions #32/#36). The artifacts are grep-scanned to guarantee zero leftovers.

**What it means for business code**: the TS/ESNext source you write is transformed by the compiler, but **complex syntax inside function bodies** (as assertions / arrow-parameter annotations / non-null assertions) must follow the [component development discipline](/docs/framework/components-develop) — the compiler's MVP limitations are itemized one by one in the rule registry.

## No DOM / No BOM

- **Forbidden**: `document.*` / `window.*` (the no-platform-api hard gate in component audits; detection goes through an optional chain on `globalThis`)
- DOM operations are the view layer's job, done by the render backend
- BOM-like info (screen/window) goes through platform capability hooks (`useScreen` and friends), never reading globals

## Modularity

| Form | Support | Artifact |
|---|---|---|
| relative-path imports | ✅ compiled into a shared module + require transform | `_proteus/<module>.js` standalone artifact |
| npm pure-logic packages | ✅ bundled into a shared module (no DOM dependency) | same as above |
| packages that depend on DOM/BOM | ❌ cannot run in the logic layer | — |

> Unresolvable imports warn explicitly at compile time (anti-black-box: no more silent stripping).

## Global objects

| Object | Source | Purpose |
|---|---|---|
| `getApp()` | host | the app instance (mount point of the provide registry) |
| `getCurrentPages()` | host | the page stack (provide namespace resolution) |
| `wx` | platform | normalized through the `@proteus-vue/api` bridge — zero direct calls from business code (CMP007 api-check gate) |
