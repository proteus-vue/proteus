## Props

| Prop | Doc | Type | Default | Required |
|---|---|---|---|---|
| `axis` | Scroll axis: x horizontal / y vertical / both | `String` | `'y'` | No |
| `paging` | Paging snap (capability constraint - B2 declaration only) | `Boolean` | `false` | No |
| `refresh` | Pull-to-refresh (capability constraint - B2 declaration only) | `Boolean` | `false` | No |
| `indicator` | Scroll indicator | `Boolean` | `true` | No |

## Implementation notes

- Use only when a scroll semantic is needed (aligned with scroll-view); axis controls the direction, CSS overflow implements Web scrolling
- ★B2 scope: basic scroll container (paging/refresh/indicator are capability constraints - to be wired in later batches)
- Dual-end single source: div → view; Web scrolls via overflow

## Usage

```vue
<p-scroll :axis="…">
  <p-text>content</p-text>
</p-scroll>
```
