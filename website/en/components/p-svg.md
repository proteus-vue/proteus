## Props

| Prop | Doc | Type | Default | Required |
|---|---|---|---|---|
| `path` | SVG path d data (no fill semantics -- follows currentColor) | `String` | `''` | No |
| `viewbox` | View box "x y w h" (defaults to 0 0 24 24) | `String` | `'0 0 24 24'` | No |
| `size` | Size in px | `Number` | `24` | No |
| `color` | Color | `String` | `'currentColor'` | No |

## Implementation notes

- path (SVG path d data) + viewbox rendering; vector-first (no bitmaps)
- ★B2 Web-first: inline svg element (Skia vector mapping on the MP side in a later batch)

## Usage

```vue
<p-svg :path="…">
  <p-text>content</p-text>
</p-svg>
```
