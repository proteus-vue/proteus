## Props

| Prop | Doc | Type | Default | Required |
|---|---|---|---|---|
| `minSplitWidth` | Container width reaches this value → side-by-side panes (px; below it → stacked) | `Number` | `640` | No |
| `gap` | Spacing between panes / stacked sections (px) | `Number` | `16` | No |
| `designWidth` | Design width (baseline for deriving the container breakpoint) | `Number` | `375` | No |

## Implementation notes

- Container width < minSplitWidth → stacked (column); ≥ → side-by-side (row) -- resolved by the container, not the viewport
- Thin shell referencing @proteus-vue/fluid (the createContainerQuery container-query runtime)
- ★MP safety: generic ref falls back (no ResizeObserver on MP → keeps the stacked default); the as in the method body can be stripped

## Usage

```vue
<p-split :minSplitWidth="…">
  <p-text>content</p-text>
</p-split>
```
