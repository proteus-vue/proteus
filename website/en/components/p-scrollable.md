## Props

| Prop | Doc | Type | Default | Required |
|---|---|---|---|---|
| `bounce` | Elastic scrolling (iOS rubber-band) | `Boolean` | `false` | No |
| `refresh` | Pull-down refresher (semantic declaration -- native implementation lands in a later batch) | `Boolean` | `false` | No |
| `loadMore` | Load more when scrolled to the bottom | `Boolean` | `false` | No |
| `loading` | Loading state (footer text toggling) | `Boolean` | `false` | No |
| `height` | Visible height in px (0 = inherit/adapt) | `Number` | `0` | No |

## Events

| Event | Doc |
|---|---|
| `load-more` | Load more (pagination on reaching the bottom) |
| `refresh` | Refresh triggered |

## Implementation notes

- Scroll container + bounce (elastic) + refresh (emit on pull-down refresher) + loadMore (emit load when scrolled to the bottom)
- Web implementation: overflow scrolling + scroll event detection (the refresher pull will be wired to native gestures in a later batch)
- Same source for both ends: div → view; refresh/bounce on MP/native are handled by the platform scroll component

## Usage

```vue
<p-scrollable :bounce="…">
  <p-text>content</p-text>
</p-scrollable>
```
