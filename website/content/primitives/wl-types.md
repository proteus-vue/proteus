## 用法与降级

- **入口**：`shared(initial)` / `derived(fn)` 建共享值 → `timing/spring/decay` 描述动画 → `applyAnimatedStyle(scope, selector, updater, config)` 绑定到组件样式（返回解绑函数）
- **模板侧零运行时 API**：`worklet:style="{{animatedStyle}}"` 由**编译器透传**官方 WXML 前缀（无需 import）
- **诚实降级**：非 Skyline（WebView / Web / SSR）→ 同 API 的 JS 线程 rAF 插值，`hasWorklet() === false` / `real === false`，**不假装有 UI 线程隔离**
- **能力探测**：用 `hasWorklet()` 判「真·小程序 + Skyline 渲染器 + `wx.worklet` 存在」三者齐备；组件层能力矩阵 SSOT 见 `@proteus-vue/shared` 的 `detectMpRenderer`
- 真实消费：`packages/components/runtime/capability.ts` 的 `hasWorklet()` 能力探测；Skyline 侧限制见 [Skyline 踩坑总账](/docs/framework/skyline-pitfalls)
