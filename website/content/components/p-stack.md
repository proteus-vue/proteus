## Props

| Prop | 说明 | 类型 | 默认值 |
|---|---|---|---|
| `direction` | 主轴方向：row（横向）/ column（纵向） | `String` | `'column'` |
| `wrap` | 空间不足自动换行（仅 row） | `Boolean` | `false` |
| `gap` | 子项间距（px） | `Number` | `0` |

## 实现要点

- 方向 + 间距 + 智能换行：Web = flex + gap（wrap 时空间不足自动换行）
- 双端同源码：div → view（编译期映射）

## 用法

```vue
<p-stack :direction="…">
  <p-text>内容</p-text>
</p-stack>
```
