## Props

| 属性 | 说明 | 类型 | 默认值 | 必填 |

## 实现要点

- options[{value,label}] + multiple + searchable + cascader（B2 基础：单选/多选面板；searchable/cascader 后续批次）
- ★B2 Web-first：自绘下拉面板（div）；MP 端映射 picker/弹层后续批次
- 双端同源码；无平台 API（文档级监听禁——用遮罩点击关闭，对齐 p-drawer 模式）
