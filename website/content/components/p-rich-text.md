## 实现要点

- source HTML/markdown → 渲染；Web v-html 直渲，MP 编译器映射 rich-text node
- ★B2 Web-first：source 透传 v-html（MP 端待 rich-text node 映射后续批次）
- 双端同源码：div → view；无平台 API
