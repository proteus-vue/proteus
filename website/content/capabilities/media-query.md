# useMediaQuery

**它能做什么**：按屏幕尺寸等条件监听"当前是哪种布局断点"。

**什么时候用**：响应式布局、平板/手机不同排版。

> 技术标识：能力原语 C60 · `capability.media-query` · 返回 `MediaQueryObserver` · **Hook 已实现**（各端支持情况见下方兼容进度表）

★C60 useMediaQuery：媒体查询句柄（wx.createMediaQueryObserver / web matchMedia）

## 签名

```ts
useMediaQuery(): CapResult<MediaQueryObserver>
```

## 返回值

`Promise<CapResult<T>>`——铁律：无回调、无 try/catch 义务，`res.ok` 分支处理：

| 属性 | 类型 | 说明 |
|---|---|---|
| `ok` | `boolean` | 成功 `true` / 失败 `false` |
| `data` | `MediaQueryObserver` | 成功载荷（方法结构见下） |
| `error` | `CapError` | 失败时存在：`code`（机器码）/ `message`（人读原因）/ `cause`（原始异常） |

## 方法

| 方法 | 说明 |
|---|---|
| [`observe`](#observe) | 开始观察媒体查询条件。 |
| [`disconnect`](#disconnect) | 停止观察（释放） |

### `observe`

```ts
observe(condition: MediaQueryCondition, cb: (result: MediaQueryResult) => void): void
```

**说明**：开始观察媒体查询条件。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `condition` | `MediaQueryCondition` | 是 | 条件（宽高范围 / 方向） |
| `cb` | `(result: MediaQueryResult) => void` | 是 | 匹配状态变化回调 |

**返回值**：`void`

### `disconnect`

```ts
disconnect(): void
```

**说明**：停止观察（释放）

**返回值**：`void`

## 类型引用

### `MediaQueryCondition`

媒体查询条件（wx MediaQueryObserver.observe options——对齐官方字段）

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|

## 错误码

| code | 说明 |
|---|---|
| `element.unsupported` | 桥未提供 createMediaQuery（useMediaQuery 不可用） |

> 平台不支持 → `*.unsupported` 族；业务按 code 分支处理，无需 try/catch。

## 用法

```ts
const mq = useMediaQuery() // 同步句柄——无 await、无 res.ok

if (mq.ok) {
  mq.data.observe({ minWidth: 600, orientation: 'landscape' }, (res) => {
    console.log('宽屏:', res.matches)
  })
  // mq.data.disconnect() 停止观察
} else if (mq.error.code === 'element.unsupported') {
  // 桥未提供媒体查询 API → 降级路径
}
```
