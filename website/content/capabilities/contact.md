# useContact

**它能做什么**：从通讯录选择一个联系人。

**什么时候用**：填写收货人、邀请好友。

> 技术标识：能力原语 C19 · `capability.contact` · 返回 `Result<Contact[]>` · **Hook 已实现**（各端支持情况见下方兼容进度表）

useContact：联系人选择（wx.chooseContact；web 无标准 → Err 降级）

## 签名

```ts
useContact(): Promise<CapResult<Contact[]>>
```

## 返回值

`Promise<CapResult<T>>`——铁律：无回调、无 try/catch 义务，`res.ok` 分支处理：

| 属性 | 类型 | 说明 |
|---|---|---|
| `ok` | `boolean` | 成功 `true` / 失败 `false` |
| `data` | `Contact[]` | 成功载荷（结构见下） |
| `error` | `CapError` | 失败时存在：`code`（机器码）/ `message`（人读原因）/ `cause`（原始异常） |

## 属性

| 属性 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | `string` | 是 | 联系人姓名 |
| `phone` | `string` | 否 | 电话号码 |
| `email` | `string` | 否 | 邮箱 |

## 错误码

| code | 说明 |
|---|---|
| `contact.unsupported` | 桥未提供 chooseContact（useContact 不可用） |
| `contact.failed` | wx.chooseContact 失败 |

> 平台不支持 → `*.unsupported` 族；业务按 code 分支处理，无需 try/catch。

```ts
  // 平台不支持 → 降级路径
}
```
