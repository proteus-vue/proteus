# useLocation

**它能做什么**：拿到用户的经纬度（GPS 或基站定位）。

**什么时候用**：附近门店、打卡、配送地址。

> 技术标识：能力原语 C3 · `capability.location` · 返回 `Result<Coords>` · **Hook 已实现**（各端支持情况见下方兼容进度表）

位置（wx.getLocation / navigator.geolocation / mock）

## 签名

```ts
useLocation(): Promise<CapResult<Coords>>
```

## 返回值

`Promise<CapResult<T>>`——铁律：无回调、无 try/catch 义务，`res.ok` 分支处理：

| 属性 | 类型 | 说明 |
|---|---|---|
| `ok` | `boolean` | 成功 `true` / 失败 `false` |
| `data` | `Coords` | 成功载荷（结构见下） |
| `error` | `CapError` | 失败时存在：`code`（机器码）/ `message`（人读原因）/ `cause`（原始异常） |

| 属性 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `latitude` | `number` | 是 | 纬度（WGS84，浮点度数） |
