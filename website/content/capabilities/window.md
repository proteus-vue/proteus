## 用法

```ts
const win = useWindow() // 同步句柄——无 await、无 res.ok

if (win.ok) {
  await win.data.setSize(1280, 720) // PC 端调整窗口（需屏幕足够大）
} else if (win.error.code === 'window.unsupported') {
  // 非 PC 端 / Web 无标准 → 降级路径
}
```

## 平台专栏

### 小程序（MP）

- **wx.setWindowSize（PC 端）** — 仅微信 PC 端支持设置窗口尺寸；移动端无此 API（诚实 Err）

### Web

- **浏览器窗口尺寸受限** — window.resizeTo 仅对脚本打开的弹出窗口有效——普通页签无法改尺寸（诚实 Err，不假装成功）

### App（iOS / Android / 鸿蒙）

- **原生窗口管理（分屏 / 折叠屏 / 桌面）** — iPad 分屏、折叠屏多窗口、桌面端自由缩放——壳转发原生窗口 API（iOS UIWindowScene / Android WindowManager） · 规划中: 壳实现 `window.setSize` 后本端可用
- **尺寸变化通知** — 窗口尺寸变化经 app:resize 事件送达（无需轮询）——分屏/旋转时业务可重排布局 · 相关能力: [`useBackground`](/docs/capability/background)
