# useExtension

**它能做什么**：加载宿主提供的扩展/插件能力。

**什么时候用**：宿主注入的业务扩展点。

**端实现边界**：iOS **禁止**动态加载第三方代码（App Store 政策）；Android/鸿蒙可用宿主侧注册表实现。

> 技术标识：能力原语 C50 · `capability.extension` · 返回 `ExtensionAPI` · **Hook 已实现**（各端支持情况见下方兼容进度表）

useExtension：扩展/插件（G-21 扩展点——宿主 loadPlugin 桥；缺省 Err）

## 签名

```ts
useExtension(extensionId: string): Promise<CapResult<unknown>>
```

## 参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `extensionId` | `string` | 是 | 扩展/插件 ID（G-21 扩展点登记名） |

## 返回值

`Promise<CapResult<T>>`——铁律：无回调、无 try/catch 义务，`res.ok` 分支处理：

| 属性 | 类型 | 说明 |
|---|---|---|
| `ok` | `boolean` | 成功 `true` / 失败 `false` |
| `data` | `unknown` | 成功载荷 |
| `error` | `CapError` | 失败时存在：`code`（机器码）/ `message`（人读原因）/ `cause`（原始异常） |

## 类型引用

### `CapError`

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `code` | `string` | — | — |
| `message` | `string` | — | — |
| `cause` | `unknown` | — | — |

## 错误码

| code | 说明 |
|---|---|
| `extension.unsupported` | 桥未提供 loadExtension（useExtension 不可用） |

> 平台不支持 → `*.unsupported` 族；业务按 code 分支处理，无需 try/catch。

> 状态口径：✅ 端已落地·本能力可用；⚠️ 端已落地·桥未提供**或桥是纯空壳**→Err 显式降级（方法存在但每一条路径都返回 unsupported 不算可用）；🟡 能力桥未接线；⬜ 端未开始。★**各端判据严格度不同**：微信/Web 要求桥方法存在**且方法体真有平台对接**；iOS/Android 要求 App 桥工厂里有该方法；鸿蒙要求 JS 桥 + 宿主分派**双证据**。端架构对照见 [端与成熟度](/docs/framework/ends-matrix)。

> 铁律：能力原语全部返回 `Result<T>`（无回调 / 无全局对象）；平台不支持 → `Err` 显式降级，业务零平台分支。

## 用法

```ts
const res = await useExtension('com.acme.exporter')

if (res.ok) {
  console.log('扩展返回:', res.data)
} else if (res.error.code.endsWith('.unsupported')) {
  // 平台不支持 → 降级路径
}
```

## 平台专栏

### 小程序（MP）

- **无插件加载 API** — 小程序端不能运行时加载外部代码——需宿主扩展壳（同层渲染 / 动态组件）承接，见 docs/proteus-platform-plan

### Web

- **动态 import()** — 运行时加载 ES 模块（真实实现）；只接受模块 URL（相对/绝对/http(s)）——不透传裸标识符

### App（iOS / Android / 鸿蒙）

- **壳动态装载原生模块（G-45 同机制）** — App 端可动态装载原生模块（Android DexClassLoader / iOS 动态库）——与调试基座的插件装载同机制 · 规划中: 壳实现 `extension.load` 后本端可用
