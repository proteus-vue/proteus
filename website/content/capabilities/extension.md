# useExtension

useExtension：扩展/插件（G-21 扩展点——宿主 loadPlugin 桥；缺省 Err）

> 能力原语 C50 · `capability.extension` · 返回 `ExtensionAPI` · **Hook 已实现**（API 就绪，双端桥见下表）

## 签名

```ts
useExtension(extensionId: string): Promise<CapResult<unknown>>
```

## 平台等价

| 端 | 等价物 |
|---|---|
| 小程序 | 无（插件/扩展点 G-21） |
| Web | 平台桥（wx 缺席时 webBridge 实现；不支持 → `Err('capability.extension.unsupported')`） |

> 铁律：能力原语全部返回 `Result<T>`（无回调 / 无全局对象）；平台不支持 → `Err` 显式降级，业务零平台分支。

```ts
  // 平台不支持 → 降级路径
}
```
