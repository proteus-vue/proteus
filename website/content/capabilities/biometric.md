# useBiometric

**它能做什么**：调指纹/人脸做本机身份校验。

**什么时候用**：支付确认、敏感操作二次验证。

**端实现边界**：仅"本机校验"（指纹/面容）——**不是**服务端可验证的凭据；需要服务端确认时请与自有鉴权组合。

> 技术标识：能力原语 C38 · `capability.biometric` · 返回 `Result<boolean>` · **Hook 已实现**（各端支持情况见下方兼容进度表）

useBiometric：生物识别支持性检测

## 签名

```ts
useBiometric(): Promise<CapResult<boolean>>
```

## 返回值

`Promise<CapResult<T>>`——铁律：无回调、无 try/catch 义务，`res.ok` 分支处理：

| 属性 | 类型 | 说明 |
|---|---|---|
| `ok` | `boolean` | 成功 `true` / 失败 `false` |
| `data` | `boolean` | 成功载荷 |
| `error` | `CapError` | 失败时存在：`code`（机器码）/ `message`（人读原因）/ `cause`（原始异常） |

## 错误码

| code | 说明 |
|---|---|
| `biometric.unsupported` | 桥未提供 checkBiometricSupport（useBiometric 不可用） |
| `biometric.failed` | 生物识别认证失败 |

> 平台不支持 → `*.unsupported` 族；业务按 code 分支处理，无需 try/catch。
