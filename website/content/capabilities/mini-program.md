# useMiniProgram

useMiniProgram：跳小程序（wx.navigateToMiniProgram / web → Err）

> 能力原语 C47 · `capability.mini-program` · 返回 `MPContext` · **Hook 已实现**（API 就绪，双端桥见下表）

## 签名

```ts
useMiniProgram(): Promise<CapResult<MiniProgramAPI>>
```

## 返回值

`Promise<CapResult<T>>`——铁律：无回调、无 try/catch 义务，`res.ok` 分支处理：

| 属性 | 类型 | 说明 |
|---|---|---|
| `ok` | `boolean` | 成功 `true` / 失败 `false` |
| `data` | `MiniProgramAPI` | 成功载荷（结构见下） |
| `error` | `CapError` | 失败时存在：`code`（机器码）/ `message`（人读原因）/ `cause`（原始异常） |

## 错误码

| code | 说明 |
|---|---|
| `mini-program.unsupported` | 桥未提供 navigateMiniProgram（useMiniProgram 不可用） |

> 平台不支持 → `*.unsupported` 族；业务按 code 分支处理，无需 try/catch。
