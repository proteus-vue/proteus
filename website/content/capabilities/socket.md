# useSocket

**它能做什么**：直接用 UDP/TCP 收发原始字节。

**什么时候用**：物联网设备通信、自定义协议。

> 技术标识：能力原语 C69 · `capability.socket` · 返回 `UDPSocketHandle / TCPSocketHandle` · **Hook 已实现**（各端支持情况见下方兼容进度表）

★C69 useSocket：底层网络 Socket（wx.createUDPSocket/createTCPSocket；web 无裸 socket → Err）

## 签名

```ts
useSocket(): CapResult<{ udp(): UDPSocketHandle; tcp(options?: TCPSocketConnectOptions): TCPSocketHandle }>
```

## 返回值

`Promise<CapResult<T>>`——铁律：无回调、无 try/catch 义务，`res.ok` 分支处理：

| 属性 | 类型 | 说明 |
|---|---|---|
| `ok` | `boolean` | 成功 `true` / 失败 `false` |
| `data` | `{ udp(): UDPSocketHandle; tcp(options?: TCPSocketConnectOptions): TCPSocketHandle }` | 成功载荷 |
| `error` | `CapError` | 失败时存在：`code`（机器码）/ `message`（人读原因）/ `cause`（原始异常） |

## 类型引用

### `UDPSocketHandle`

★权威标尺缺口 C69-a：UDP Socket（`useUDPSocket()`）。
wx：`wx.createUDPSocket()`；web：无 UDP 标准 API（浏览器不支持裸 UDP）→ Err 诚实降级。

| 方法 | 签名 | 说明 |
|---|---|---|
| `bind` | `bind(port?: number): Promise<CapResult<void>>` | 绑定本地端口（缺省系统分配） |
| `connect` | `connect(address: string, port: number): Promise<CapResult<void>>` | 预连目标地址（配合 write）。 |
| `send` | `send(address: string, port: number, message: string \| ArrayBuffer, broadcast?: boolean): Promise<CapResult<void>>` | 发送消息。 |
| `write` | `write(address: string, port: number, message: string \| ArrayBuffer): Promise<CapResult<void>>` | 向已 connect 的地址发送（少写地址；需先 connect）。 |
| `onMessage` | `onMessage(cb: (msg: UdpMessage) => void): () => void` | 订阅收到的消息。 |
| `onError` | `onError(cb: (err: { errMsg: string }) => void): () => void` | 订阅错误 |
| `close` | `close(): Promise<CapResult<void>>` | 关闭 socket（释放） |

> 铁律：能力原语全部返回 `Result<T>`（无回调 / 无全局对象）；平台不支持 → `Err` 显式降级，业务零平台分支。

## 用法

```ts
const sock = useSocket() // 同步句柄——无 await、无 res.ok

if (sock.ok) {
  const udp = sock.data.udp()
  await udp.bind(8080)
  udp.onMessage((m) => console.log('收到:', m.remoteAddress, m.remotePort))
  await udp.send('192.168.1.1', 9000, 'ping')
  // 或 TCP：const tcp = sock.data.tcp(); await tcp.connect({ address, port })
} else if (sock.error.code === 'socket.unsupported') {
  // Web 浏览器不支持裸 socket → 降级路径（WebSocket/WebRTC）
}
```
