## 用法

```ts
const guard = useNavigationGuard() // 同步句柄——无 await、无 res.ok

if (guard.ok) {
  await guard.data.enable('表单未保存，确认离开？')
  // 保存成功后：await guard.data.disable()
} else if (guard.error.code === 'navigation-guard.unsupported') {
  // 平台不支持 → 降级路径
}
```

## 平台专栏

### 小程序（MP）

- **wx.enableAlertBeforeUnload** — 返回时弹出确认框（防误退丢草稿）——需基础库 2.12.0+；仅拦截"返回"，不拦截"关闭小程序"

### Web

- **beforeunload 的浏览器限制** — 浏览器只允许"询问是否离开"，**不能自定义文案**（现代浏览器强制显示通用提示）

### App（iOS / Android / 鸿蒙）

- **虚拟栈 pop 拦截（框架内完成）** — ★App 端无需原生 API：虚拟栈的 pop 是框架自己的命令（M5）⇒ 拦截在框架内完成，可自定义弹层与文案 · 相关能力: [`usePageLifecycle`](/docs/capability/page-lifecycle)
- **Android 物理返回键** — 实体/手势返回同样经栈 pop 派发——与 UI 返回一致（壳负责把 onBackPressed 转成虚拟栈 pop） · 规划中: 壳接线 onBackPressed → 栈 pop 后生效
