# useInAppPurchase

useInAppPurchase：内购（wx/无公开 API → Err 诚实降级）

> 能力原语 C46 · `capability.in-app-purchase` · 返回 `Result<Receipt>` · **Hook 已实现**（API 就绪，双端桥见下表）

## 签名

```ts
useInAppPurchase(productId: string): Promise<CapResult<IAPReceipt>>
```

## 参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `productId` | `string` | 是 | 内购商品 ID（应用商店登记） |

## 返回值

`Promise<CapResult<T>>`——铁律：无回调、无 try/catch 义务，`res.ok` 分支处理：

| 属性 | 类型 | 说明 |
|---|---|---|
| `ok` | `boolean` | 成功 `true` / 失败 `false` |
| `data` | `IAPReceipt` | 成功载荷（结构见下） |
| `error` | `CapError` | 失败时存在：`code`（机器码）/ `message`（人读原因）/ `cause`（原始异常） |

#### `data`（`IAPReceipt`）的属性

| 属性 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `productId` | `string` | 是 | 内购商品 ID（应用商店登记） |
| `transactionId` | `string` | 否 | 交易单号（商店返回） |
| `state` | `'purchased' | 'restored'` | 是 | 交易状态（purchased 新购 / restored 恢复购买） |
