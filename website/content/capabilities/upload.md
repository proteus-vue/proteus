# useUpload

**它能做什么**：上传文件到服务器，并拿到进度。

**什么时候用**：上传头像、证件、视频。

> 技术标识：能力原语 C29 · `capability.upload` · 返回 `Progress<Result>` · **Hook 已实现**（各端支持情况见下方兼容进度表）

useUpload：上传文件（wx.uploadFile / web fetch FormData）

## 签名

```ts
useUpload(options: UploadOptions, onProgress?: ProgressCallback): Promise<CapResult<UploadResult>>
```

## 参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `options` | `UploadOptions` | 是 | C29 上传选项（wx.uploadFile / web fetch FormData） |
| `onProgress` | `ProgressCallback` | 否 | C29/C30 传输进度回调（0-100） |

## 返回值

`Promise<CapResult<T>>`——铁律：无回调、无 try/catch 义务，`res.ok` 分支处理：

| 属性 | 类型 | 说明 |
|---|---|---|
| `ok` | `boolean` | 成功 `true` / 失败 `false` |
| `data` | `UploadResult` | 成功载荷（结构见下） |
| `error` | `CapError` | 失败时存在：`code`（机器码）/ `message`（人读原因）/ `cause`（原始异常） |

## 错误码

| code | 说明 |
|---|---|
| `upload.unsupported` | 桥未提供 upload（useUpload 不可用） |
| `upload.failed` | wx 上传缺少 filePath |

> 平台不支持 → `*.unsupported` 族；业务按 code 分支处理，无需 try/catch。

> 状态口径：✅ 端已落地·本能力可用；⚠️ 端已落地·桥未提供**或桥是纯空壳**→Err 显式降级（方法存在但每一条路径都返回 unsupported 不算可用）；🟡 能力桥未接线；⬜ 端未开始。★**各端判据严格度不同**：微信/Web 要求桥方法存在**且方法体真有平台对接**；iOS/Android 要求 App 桥工厂里有该方法；鸿蒙要求 JS 桥 + 宿主分派**双证据**。端架构对照见 [端与成熟度](/docs/framework/ends-matrix)。

## 用法

```ts
const res = await useUpload({ url: 'https://api.example.com/upload', filePath })

if (res.ok) {
  console.log('上传完成:', res.data.status, res.data.progress ?? 100)
} else if (res.error.code.endsWith('.unsupported')) {
  // 平台不支持 → 降级路径
}
```
