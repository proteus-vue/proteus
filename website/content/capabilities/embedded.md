# useEmbedded

useEmbedded：宿主嵌入上下文（被嵌入场景——宿主桥；缺省 Err）

> 能力原语 C48 · `capability.embedded` · 返回 `HostContext` · **Hook 已实现**（API 就绪，双端桥见下表）

## 签名

```ts
useEmbedded(): Promise<CapResult<HostContext>>
```

## 返回值

`Promise<CapResult<T>>`——铁律：无回调、无 try/catch 义务，`res.ok` 分支处理：

| 属性 | 类型 | 说明 |
|---|---|---|
| `ok` | `boolean` | 成功 `true` / 失败 `false` |
| `data` | `HostContext` | 成功载荷（结构见下） |
| `error` | `CapError` | 失败时存在：`code`（机器码）/ `message`（人读原因）/ `cause`（原始异常） |

## 属性

| 属性 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `provider` | `string` | 是 | 宿主渠道标识（wechat / web / studio …） |
| `version` | `string` | 否 | 宿主/基础库版本 |
| `capabilities` | `string[]` | 否 | 宿主声明的能力名集合 |

## 错误码

| code | 说明 |
|---|---|
| `embedded.unsupported` | 桥未提供 getHostContext（useEmbedded 不可用） |

> 平台不支持 → `*.unsupported` 族；业务按 code 分支处理，无需 try/catch。

## 用法

```ts
const res = await useEmbedded()

if (res.ok) {
  console.log('宿主:', res.data.provider)
} else if (res.error.code.endsWith('.unsupported')) {
  // 平台不支持 → 降级路径
}
```

## 平台专栏

### 小程序（MP）

- **无"被嵌入"形态** — 小程序总是运行在微信宿主内（不存在"被别的 App 嵌入"）——provider 恒为 weixin

### Web

- **iframe 嵌入与父窗口** — Web 的"被嵌入"= iframe——provider=web，父窗口经 window.parent 可达（跨域时受限）

### App（iOS / Android / 鸿蒙）

- **被宿主 App 嵌入（核心场景）** — App 端"被嵌入"是一等场景（AAR / 静态库集成）——宿主经 `__PROTEUS_HOST_ID__` 自述身份，业务据此定制行为
