# useStorage

useStorage：存储句柄（响应式增强见 createReactiveStorage）

> 能力原语 C15 · `capability.storage` · 返回 `StorageAPI` · **Hook 已实现**（API 就绪，双端桥见下表）

## 签名

```ts
useStorage(): CompatStorage
```

## 返回值

返回 `CompatStorage`（同步句柄——无 Promise、无 await，结构见下）。

## 用法

```ts
const store = useStorage() // 同步句柄——无 await、无 res.ok

store.set('theme', 'dark')
console.log('theme =', store.get('theme'))
// store.remove(key) / store.clear()；响应式增强：createReactiveStorage(store, reactive)
```
