# useSensor

useSensor：传感器一次性读取（accelerometer/compass/gyroscope）

> 能力原语 C5 · `capability.sensor` · 返回 `SensorStream` · **Hook 已实现**（API 就绪，双端桥见下表）

## 签名

```ts
useSensor(kind: SensorKind): Promise<CapResult<SensorSample>>
```

## 平台等价

| 端 | 等价物 |
|---|---|
| 小程序 | onAccelerometer/onCompass/onGyroscope |
| Web | 平台桥（wx 缺席时 webBridge 实现；不支持 → `Err('capability.sensor.unsupported')`） |

> 铁律：能力原语全部返回 `Result<T>`（无回调 / 无全局对象）；平台不支持 → `Err` 显式降级，业务零平台分支。

## 用法

```ts
const res = await useSensor()

if (res.ok) {
  console.log(res.data)
} else if (res.error.code.endsWith('.unsupported')) {
  // 平台不支持 → 降级路径
}
```
