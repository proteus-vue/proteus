# useWorker

**它能做什么**：把耗时计算放到后台线程，避免卡住界面。

**什么时候用**：大文件解析、复杂计算、加解密。

> 技术标识：能力原语 C53 · `capability.worker` · 返回 `WorkerHandle` · **Hook 已实现**（各端支持情况见下方兼容进度表）

★C53 useWorker：多线程 Worker（wx.createWorker / web Worker；不可用 → Err）

## 平台专栏

### 小程序（MP）

- **wx.createWorker（真线程）** — 小程序多线程 Worker：独立 JS 上下文，postMessage 通信——需在 app.json 声明 worker 目录

### Web

- **Web Worker（真线程）** — new Worker(url) 独立线程；onMessage 可用 removeEventListener 取消（比 MP 更完整）
- **跨线程数据限制** — 结构化克隆（非引用传递）；大对象建议 Transferable（ArrayBuffer 转移所有权，零拷贝）

### App（iOS / Android / 鸿蒙）

- **壳后台线程（G-39 runOnThread）** — App 端的"线程"由宿主运行时提供（G-39 唯一拥有）——桥经壳创建，业务不直接建线程 · 规划中: 壳实现 `worker.create/post/terminate` 后本端可用
