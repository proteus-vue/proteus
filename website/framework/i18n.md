# 国际化

跨端消息目录 + ICU 子集 + **类型安全 `t()`**（`@proteus-vue/i18n`）。**类型安全免 codegen**：`as const` catalog + `keyof` 推导 MessageKey——写错 key 编译期即报。

## 创建与 API 全表

```ts
import { createI18n } from '@proteus-vue/i18n'

// as const 声明 → keyof 类型安全（examples/locales 同构：en-US.json / zh-CN.json 实体目录）
const catalogs = {
  'zh-CN': { 'home.title': '首页', 'count': '{n} 次' },
  'en-US': { 'home.title': 'Home', 'count': '{n} times' },
} as const

export const i18n = createI18n({ catalogs, defaultLocale: 'zh-CN' })
```

| API | 签名 | 说明 |
|---|---|---|
| `i18n.locale` | `readonly string` | 当前 locale |
| `i18n.t(key, params?)` | `<K extends keyof M>(key: K, params?: FormatParams) => string` | **类型安全翻译**：key 必须是默认清单的 key；缺失消息**回退 key 本身**（i18n:check 审计可见） |
| `i18n.setLocale(locale)` | `(locale: string) => void` | 切换 locale（**未知 locale 忽略**——审计可查） |
| `i18n.dir()` | `() => 'ltr' 或 'rtl'` | 语言方向（RTL 一等公民：按 `rtlLocales` 前缀匹配） |
| `i18n.onLocaleChange(cb)` | `(cb) => void` | locale 变更回调（应用持久化 / 应用 dir 到根节点） |

`CreateI18nOptions`：`catalogs`（locale → 消息清单 as const）/ `defaultLocale`（缺省取 catalogs 首 key）/ `rtlLocales`（缺省 `ar/he/fa/ur`）。

## 插值（ICU 子集）

`t('count', { n: 5 })` → `5 次`——模板占位 `{n}` 经 `renderMessage` 渲染。ICU 全量语法之外的复杂格式用 key 拆分（i18n-plan 诚实边界）。

## 目录约定与示例

`examples/locales/` 是跨端目录的实体形态：

```
locales/
├─ index.ts      # createI18n 实例（应用侧单例，pinia 模式）
├─ en-US.json    # 英文消息目录
└─ zh-CN.json    # 中文消息目录
```

示例页 `examples/pages/i18n-demo.vue`：切换语言 → 模板内 `t()` 即时重渲染。

## 审计：`proteus i18n:check`

| 检查面 | 说明 |
|---|---|
| 硬编码文案检测 | 业务源码中未走 `t()` 的裸字符串提示 |
| catalog 键对照 | 各 locale 消息键与默认清单对照（缺失键 / 多余键） |

CI 里接 `proteus check` 聚合门禁；缺 catalog 的目录跳过不阻断（独立命令报错）。

## 跨端注意

- **MP 产物安全**：`@proteus-vue/i18n` 运行时零 `??` / `?.` / 展开 / 解构——共享模块 `_proteus/i18n` 编译进小程序产物
- locale 持久化由应用自己接（`setLocale` + `onLocaleChange` → 平台存储），框架不绑定存储形态
